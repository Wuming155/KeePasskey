# ISSUE-P3-656 S3目录XML修改时间被按HTTP日期解析而丢失

> 状态：**已闭环（2026-10-18，§540）**。生产解析、API 36 Android 兼容、独立 MinIO ListObjectsV2 / 分页 / ISO LastModified 均已验；AWS S3 未单独测试，不外推为 AWS 部署验证。

## 1. 问题与依据

ListObjects XML的LastModified使用ISO时间，但S3DirectoryList调用只认RFC1123的S3HttpDateCodec，解析失败回0。仓内fixture已含2026-10-06T00:00:00.000Z却未断言时间字段。

影响：S3目录列表元数据中的真实修改时间丢失，依赖该接口的展示或排序不能得到正确值；不外推为同步ETag失效。

- [sync/src/main/java/com/keepasskey/sync/s3/S3DirectoryList.kt](../../../../../sync/src/main/java/com/keepasskey/sync/s3/S3DirectoryList.kt)：原始行135–147。
- [sync/src/main/java/com/keepasskey/sync/s3/S3HttpDateCodec.kt](../../../../../sync/src/main/java/com/keepasskey/sync/s3/S3HttpDateCodec.kt)：原始行15–28。
- [sync/src/test/java/com/keepasskey/sync/s3/S3DirectoryListTruncationTest.kt](../../../../../sync/src/test/java/com/keepasskey/sync/s3/S3DirectoryListTruncationTest.kt)：原始行115–121。

AWS ListObjectsV2文档样例的LastModified为ISO时间；依据：[官方ListObjectsV2](https://docs.aws.amazon.com/AmazonS3/latest/API/API_ListObjectsV2.html)。

1. 向parseListObjects提供仓内合规fixture时间。
2. 读取entries首项lastModifiedMillis。
3. 当前为0，预期对应UTC epoch毫秒；同时确认HTTP Last-Modified头仍能按RFC1123解析。

反证与限制：HTTP响应头使用此codec是正确用途；问题在XML消费者复用错格式。 本轮没有运行产品、服务或新增运行测试。

## 2. 修复目标与边界

XML时间与HTTP日期各按自身协议解析，未知值和1970时间可区分。

模块：sync S3DirectoryList/S3HttpDateCodec/RemoteListEntry。预期结果：目录元数据保留S3返回的真实LastModified。

## 3. 实施步骤与失败处理

1. 为ListObjects XML使用ISO-8601解析器，明确无小数/毫秒/Z和允许偏移的处理。
2. 保持HTTP头原有RFC1123路径；无效XML日期有可解释降级。
3. 补fixture时间断言，避免只验证列表数量。

失败必须如实返回，不伪装成功/空列表；不打印请求认证材料，工作副本按所有权在finally清理。接口调整同时检查所有调用方，不修改生产凭据或真实远端数据。

## 4. 验收矩阵

- 官方ISO样例、无小数/毫秒/时区/非法值与HTTP头正负对照。
- RemoteListEntry回读时间准确，ETag和大小不受改变。

验收用例是后续计划，不是已通过结果。实现、编译/JVM/设备、真实S3端到端尚未执行。设备用例若新增/修改必须在隔离AVD或可丢弃设备实际运行并确认非空XML。

### 4.1 实施与设备端补验（2026-10-18）

- 设备端首次实跑暴露平台兼容缺陷：Android API 36 的 `DocumentBuilderFactory` 不支持原代码强制设置的
  三项 JAXP/Apache 特性，`ParserConfigurationException` 使任何 S3 目录列举被降级为失败。现改为逐项
  按平台支持启用；不支持的平台仍使用空白 `EntityResolver` 阻断外部实体。
- 新增 `sync/src/androidTest/.../S3XmlAndDerivationDeviceTest.kt`，在隔离 AVD
  `KeePasskeyRemediation_API36` / API 36 经 Gradle `connectedDebugAndroidTest` 实跑：
  `tests=4 failures=0 errors=0 skipped=0`。
- 读数：设备回环 `listRemoteDirectory` 将 `2026-10-06T00:00:00.000Z` 与
  `2026-10-06T08:00:00+08:00` 都读为 `1791244800000`；含 `&` 的前缀、含
  `& / = / %2F / +` 的续页 token 均保持为单个 query 参数，续页固定 5 项参数。
- 安全对照：在 JAXP 特性不受支持的同一平台上，带外部实体的 `Key` 未展开本地 canary 文件，
  外部 DTD 也未改变合法 key；对同一解析入口的无 DOCTYPE 报文正常解析，排除「整篇失败」假阴性。
- 仍未覆盖：真实 S3 / MinIO 等独立服务的 ListObjectsV2 回执。`MockWebServer` 只能证明设备运行时、
  wire query 与解析链，不构成服务端互操作证据。
