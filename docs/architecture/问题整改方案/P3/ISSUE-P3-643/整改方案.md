# ISSUE-P3-643 重复选择自定义图标会清掉其它未保存编辑的脏标记

> 状态：**尚未实施**。核实：2026-10-16（Asia/Shanghai）；源码基线：`94172d1efca004692b68ea480a1516753087fd70`。
> 等级：P3；结论：静态确认；置信度：高。本轮只记录审查和方案，不修改业务代码。

## 1. 问题与依据

onCustomIconSelected直接设置isDirty=(旧customIconId!=新id)，没有保留旧isDirty。用户已编辑标题/密码后选择当前相同图标，或连续选择同一新图标，脏位变false。

- 审查维度：用户体验与易用性、数据流转与一致性。
- 影响范围：离页不弹丢弃确认，未保存修改容易丢失；未保存编辑登记也会错误认为没有草稿。
- 核实方式：当前源码调用链、状态转换及相关测试源码核对；下列产品复现序列未实跑。

- [app/src/main/java/com/keepasskey/app/ui/screens/edit/EntryEditViewModel.kt](../../../../../app/src/main/java/com/keepasskey/app/ui/screens/edit/EntryEditViewModel.kt)：原始行 307–310。
- [app/src/main/java/com/keepasskey/app/ui/screens/edit/EntryEditScreen.kt](../../../../../app/src/main/java/com/keepasskey/app/ui/screens/edit/EntryEditScreen.kt)：原始行 204–208。

复现/验证路径：

1. 编辑标题使isDirty=true。
2. 选择当前相同的自定义图标，或第一次选择某图标后再次选同一项。
3. 返回页面，观察脏位false并直接离页。

反证和限制：显式点击保存仍会保存；只在特定重复图标操作路径丢脏位。

## 2. 修复目标与边界

局部无变化事件不得清除其它字段的编辑状态。

涉及模块：app EntryEditViewModel/离页确认/UnsavedEditRegistry。

预期结果：有未保存变化必有确认，保存成功后才清脏。

保持现有产品裁决和已接受边界；方案中的新接口、屏障与测试是拟议实现，不能记作已落地。未经独立实现端到端读取/对拍，不声称 KDBX 互操作已经通过。

## 3. 实施步骤与失败处理

1. 用旧脏位OR本次变化，或与完整已加载基线比较。
2. 审查同类回调是否直接覆盖dirty；保持保存成功和重新载入才清脏。

失败处理：出现目标库/修订不匹配、IO失败或取消时，不谎报成功；保全已确认的正式文件和用户仍持有的草稿/恢复材料，明确展示部分完成边界。秘密仅在确定所有权后擦除，禁止误擦活动库共享引用。对“需要进一步验证”的后果先完成正负对照；反证成立则调整或撤销该结论，不硬凑修复。
