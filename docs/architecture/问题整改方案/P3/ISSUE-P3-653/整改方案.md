# ISSUE-P3-653 使用品牌调色盘按钮未清除残留自定义种子色

> 状态：**尚未实施**。核实：2026-10-16（Asia/Shanghai）；源码基线：`94172d1efca004692b68ea480a1516753087fd70`。
> 等级：P3；结论：静态确认；置信度：高。本轮只记录审查和方案，不修改业务代码。

## 1. 问题与依据

自定义种子色保留时开启动态取色，再点使用品牌调色盘，路由只setDynamicColorEnabled(false)。仓库该setter不清seed，resolveColorSource回到CUSTOM，品牌项继续禁用。

- 审查维度：用户体验与易用性、功能完整性。
- 影响范围：一键切回品牌配色承诺失效，用户仍停留自定义颜色；不涉及秘密或数据库内容。
- 核实方式：当前源码调用链、状态转换及相关测试源码核对；下列产品复现序列未实跑。

- [app/src/main/java/com/keepasskey/app/ui/KeePasskeySettingsDisplayNavGraphRoutes.kt](../../../../../app/src/main/java/com/keepasskey/app/ui/KeePasskeySettingsDisplayNavGraphRoutes.kt)：原始行 35–40。
- [app/src/main/java/com/keepasskey/app/data/repository/RealSettingsRepository.kt](../../../../../app/src/main/java/com/keepasskey/app/data/repository/RealSettingsRepository.kt)：原始行 168–181。
- [app/src/main/java/com/keepasskey/app/ui/screens/settings/subscreens/ThemeSettingsSections.kt](../../../../../app/src/main/java/com/keepasskey/app/ui/screens/settings/subscreens/ThemeSettingsSections.kt)：原始行 220–245。

复现/验证路径：

1. 选择自定义色，再开启动态取色。
2. 点使用品牌调色盘。
3. 核对dynamic=false但seed非null，colorSource=CUSTOM，品牌项仍置灰。

反证和限制：未曾设置自定义色时该按钮可工作；直接选择品牌调色盘的仓库setter已有互斥清理。

## 2. 修复目标与边界

按钮以原子偏好事务切到品牌源，同时保留既有选中的品牌palette。

涉及模块：app 主题设置导航/RealSettingsRepository/ThemeMode。

预期结果：点击品牌按钮后实际来源为BRAND_PALETTE。

保持现有产品裁决和已接受边界；方案中的新接口、屏障与测试是拟议实现，不能记作已落地。未经独立实现端到端读取/对拍，不声称 KDBX 互操作已经通过。

## 3. 实施步骤与失败处理

1. 提供switchToBrandPalette操作，在同一DataStore事务关dynamic并清seed。
2. 导航改接该操作，保持单纯动态开关原有恢复自定义色语义（若产品仍需要）。
