# ISSUE-P3-648 生成器异步结果缺少代次校验

> 状态：**尚未实施**。核实：2026-10-16（Asia/Shanghai）；源码基线：`94172d1efca004692b68ea480a1516753087fd70`。
> 等级：P3；结论：静态竞态候选，需要进一步验证；置信度：中。本轮只记录审查和方案，不修改业务代码。

## 1. 问题与依据

每次参数变化按快照启动独立Default计算，完成后直接更新currentPassword/entropy/history，没有取消旧任务或核对代次。较早请求迟到可能覆盖当前设置对应结果；锁定清理后迟到任务重新发布也需核实。

- 审查维度：用户体验与易用性、数据流转与一致性。
- 影响范围：可能出现结果长度/模式与设置不符或锁定后重挂新生成值；未跑确定性乱序复现，不定性为已发生泄露。
- 核实方式：当前源码调用链、状态转换及相关测试源码核对；下列产品复现序列未实跑。

- [app/src/main/java/com/keepasskey/app/ui/screens/generator/GeneratorViewModel.kt](../../../../../app/src/main/java/com/keepasskey/app/ui/screens/generator/GeneratorViewModel.kt)：原始行 173–179。
- [app/src/main/java/com/keepasskey/app/ui/screens/generator/GeneratorViewModel.kt](../../../../../app/src/main/java/com/keepasskey/app/ui/screens/generator/GeneratorViewModel.kt)：原始行 222–239。

复现/验证路径：

1. 为生成任务增加测试barrier，先启动慢A，再切参数启动快B。
2. 先完成B再完成A，检查显示设置与结果。
3. 另在A未完成时触发SessionLockGuard清理，再释放A，验证是否重新发布。

反证和限制：普通快速生成多数按序完成；已有历史污染/锁定测试不等于覆盖在途任务。

## 2. 修复目标与边界

仅当前有效生成代次可以发布结果，锁定/销毁后在途结果被丢弃并清理。

涉及模块：app GeneratorViewModel/会话锁定观察者。

预期结果：生成结果不会被过期请求覆盖，锁定清理不被迟到任务撤销。

保持现有产品裁决和已接受边界；方案中的新接口、屏障与测试是拟议实现，不能记作已落地。未经独立实现端到端读取/对拍，不声称 KDBX 互操作已经通过。

## 3. 实施步骤与失败处理

1. 先用受控调度确认乱序与锁定交错，若不可达记录反证并重新评估。
2. 采用取消前任务+代次比较，结果被拒绝必须clear，避免只取消协程遗留容器。
3. 历史仅记录实际采纳结果，保留滑杆不入史策略。

失败处理：出现目标库/修订不匹配、IO失败或取消时，不谎报成功；保全已确认的正式文件和用户仍持有的草稿/恢复材料，明确展示部分完成边界。秘密仅在确定所有权后擦除，禁止误擦活动库共享引用。对“需要进一步验证”的后果先完成正负对照；反证成立则调整或撤销该结论，不硬凑修复。
