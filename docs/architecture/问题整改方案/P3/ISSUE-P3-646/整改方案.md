# ISSUE-P3-646 KDBX解密探针与内联附件解压的短命明文缓冲未清理

> 状态：**尚未实施**。核实：2026-10-16（Asia/Shanghai）；源码基线：`94172d1efca004692b68ea480a1516753087fd70`。
> 等级：P3；结论：静态确认缓冲生命周期缺口；置信度：高。本轮只记录审查和方案，不修改业务代码。

## 1. 问题与依据

解密探针累计首块到普通ByteArrayOutputStream后复制prefix，buffer/内部数组/prefix没有finally清理；内联压缩附件gunzip亦保留普通输出缓冲和拷贝buffer。它们属于解析临时独占副本，不是交付给活动库的唯一数据。

- 审查维度：安全性与权限控制、代码结构完整性。
- 影响范围：函数返回后明文副本等待GC，探针可含内层key/首块未保护字段，附件路径含明文附件。未建立远程读取或无权限获取堆的利用链；不把生命周期缺口等同已发生泄露。
- 核实方式：当前源码调用链、状态转换及相关测试源码核对；下列产品复现序列未实跑。

- [database/src/main/java/com/keepasskey/database/file/KdbxCipherKeyResolver.kt](../../../../../database/src/main/java/com/keepasskey/database/file/KdbxCipherKeyResolver.kt)：原始行 124–158。
- [database/src/main/java/com/keepasskey/database/xml/KdbxXmlBinaryNode.kt](../../../../../database/src/main/java/com/keepasskey/database/xml/KdbxXmlBinaryNode.kt)：原始行 169–196。

复现/验证路径：

1. 正常打开未压缩KDBX触发密钥探针；另构造含内联GZip附件的KDBX。
2. 在测试中注入/观测探针和解压工作缓冲，正常、结构失败、解压异常返回后检查是否清零。
3. 确认返回/交付的有效附件仍可读取，不能误擦活动库所有权。

反证和限制：外层密码/主密钥已有部分清理；堆内容可读本身需要更强访问前提；本轮只确认可避免的临时副本残留。

## 2. 修复目标与边界

临时明文工作缓冲在正常及提前返回/失败时确定清理，所有权交付副本除外。

涉及模块：database KdbxCipherKeyResolver/KdbxXmlBinaryNode/io。

预期结果：短命解析副本生命周期闭合，保留真实UI/API不可擦边界。

保持现有产品裁决和已接受边界；方案中的新接口、屏障与测试是拟议实现，不能记作已落地。未经独立实现端到端读取/对拍，不声称 KDBX 互操作已经通过。

## 3. 实施步骤与失败处理

1. 探针按实际需要流式读取最小前缀，减少整首块复制。
2. 使用可擦输出容器并覆盖扩容旧数组、读buffer及prefix的finally路径。
3. 附件解压仅移交一份结果，清理工作副本；失败不漏缓存、不误擦活动source。

失败处理：出现目标库/修订不匹配、IO失败或取消时，不谎报成功；保全已确认的正式文件和用户仍持有的草稿/恢复材料，明确展示部分完成边界。秘密仅在确定所有权后擦除，禁止误擦活动库共享引用。对“需要进一步验证”的后果先完成正负对照；反证成立则调整或撤销该结论，不硬凑修复。
