## 为什么这样拆

- 原先的整册文件达数百 KB / 上千行，难以逐条引用与审阅；拆为**一批次一文件**后每份自成一体。
- **索引只做引用、不复制正文**，避免同一结论在两处漂移。
- 例外：单批次本身即长篇（如 §42 234 行、§43 195 行、§49 190 行、§27 181 行），
  **保持整节完整**而不按小节切碎——批次叙事被切断会降低可读性。
