## 2. 让 24 处断言零改动的关键：属性别名

```kotlin
private val prefsFake = InMemorySharedPreferences()
/** 断言用别名：本类要直接检视「落盘了什么」（读密文键 20 处、预置脏键 4 处） */
private val memoryStorage: MutableMap<String, Any?> get() = prefsFake.storage
private val fakeContext: Context = prefsFake.context()
```

原实现里 `memoryStorage` 是 `private val memoryStorage = mutableMapOf(...)`，
本类**除夹具外还有 24 处直接使用它**（`assertNull(memoryStorage["webdav_password_iv"])`、
`memoryStorage["webdav_cert_pins"] = "…"` 一类）。把它改成指向共享件 `storage` 的 `get()` 别名，
24 处使用点与 `setUp()` 的 `memoryStorage.clear()` 全部原样成立——
**只放宽夹具的来源，不碰任何断言**，符合 `AGENTS.md` §3「不得以改动断言凑绿」。

## 3. 替身换实现前做过的行为差集核对（这是本批唯一的风险面）

新替身必须是旧代理的**超集或等义**，逐条比过（读两份源码，非推定）：

| 项 | 旧私有代理 | 共享件 | 判定 |
|---|---|---|---|
| `getString/getBoolean/getLong/contains/edit` | 有 | 有 | 同义 |
| `getInt/getStringSet/getAll`、`putInt/putStringSet` | **无**（落到 `else -> null`） | 有 | 超集，只会少 NPE 不会多行为 |
| `editor.apply()` | 返回 `null` | 返回 editor 代理 | `apply()` 返回 `void`，代理返回值被忽略 ⇒ 无差别 |
| `editor.commit()` | 返回 `null` ⇒ 若被调用即 **NPE** | 返回 `true` | 现无任何用例走 `commit()`（旧实现也从未暴露此路），新值更合理 |
| `hashCode/equals/toString`（`Object` 方法） | 落到 `else -> null` | 同样落到 `else -> null` | 同形，未改 |
| `Context` | 只覆写 `getSharedPreferences` | 另覆写 `getCacheDir`（临时目录） | 超集 |

⇒ 唯一**语义可变**处是 `commit()`，而它是死路（无调用方），故替换是等义的。
本批**没有**用「改坏生产代码看用例是否报红」来验证；上述差集是读实现得出的，
并以 24 处断言的字面不变 + 全量复跑为证据。
