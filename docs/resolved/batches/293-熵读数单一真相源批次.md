## 2. 整改

### 2.1 AC①：随机 / 掩码密码收敛 crypto 内核（单一真相源）

- `PasswordGenerationEngine.calculateEntropy` 改委托 `PasswordEntropyEstimator.estimateBits`（详情页既有实现，`PasswordStrengthEvaluator.guessesLog10`）——**字符集代理模型（`poolSize += 30` 的 +4 虚增一并）整体退役**，AC③ 的「poolSize 绑定」随之消解（模型不复存在，而非再绑一份）。
- `GeneratorViewModel` 生成与评估异步化（`viewModelScope.launch` + `withContext(Dispatchers.Default)`，§3 规则 2 热路径约束）；`selectHistoryPassword` 同口径。
- 编辑页：`PASSWORD_BITS_PER_CHAR = 4.5` 启发式删除；`EntryEditViewModel` 新增 `refreshPasswordEntropy`（评估副本用毕即擦、明文不进状态流、`entropySeq` 防乱序回写、载入既有条目同步评估），`EntryEditUiState.passwordEntropyBits` 供 `EntryEditFormSections` 渲染（`null` 隐藏强度条）。

### 2.2 AC②：口令短语模型

`PasswordGenerationEngine.passphraseEntropyBits` = **词数 × log2(词表) + 变形位**，变形位与 `generatePassphrase` 实际随机面逐项对齐：`includeNumber` ⇒ `log2(90)`（取值域常量化 `PASSPHRASE_NUMBER_RANGE` 并与生成单一来源）；`capitalize`（确定性）/ `separator`（用户固定）⇒ 0 位。词表规模公开为 `DICEWARE_WORD_COUNT`（模型与用例单一来源）。
