## 3. 守卫核实（本批无需扩扫）

`ObscuredTouchWiringTest` 把 `ConflictResolutionScreen.kt` 列为「以具名根 Composable 函数体为锚点」的敏感屏，
其判据只有一条：**根函数体首条语句必须是 `ApplyObscuredTouchFilter()`**（跳过空行与注释）。
本批把该语句与其下方的状态编排**留在根函数原位**，只把呈现段移出去 ⇒ 锚点未动、无需并集扩扫。
另按 §3 剩余清单第 3 项的规矩复核：`grep -rn "ConflictResolution" app/src/test` 的其余命中
（`ConflictResolutionViewModelTest` / `ConflictStrategyMappingTest` / `SyncCoordinatorTest` 等）
都是**行为级**用例而非源码文本比对 ⇒ 不受搬移影响，并由全量套件复跑覆盖。
