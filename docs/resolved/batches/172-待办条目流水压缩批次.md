## 2. 压缩的判据（哪些能删、哪些不能）

1. **可删**：「某批把某文件从 X 行降到 Y 行」的逐批流水——它的完整版本（含改动表、守卫核查、
   过程留痕、验证）在 `resolved/batches/<NN>-*.md` 里，条目只需一条汇总；
2. **不可删**：① 仍开放的剩余清单与其**排序理由**（哪些刻意排后、为什么）；② 三处「刻意不搬」的
   边界（各自锚着哪个守卫或设备级证据）；③ 验收标准里「不得读作已闭环」那类**反向护栏**；
   ④ 度量口径（`wc -l` + 最终写盘后取数）——口径一旦丢掉，下一批就会重新积累漂移数字。
