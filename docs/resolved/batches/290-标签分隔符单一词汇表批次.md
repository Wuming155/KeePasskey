## 2. 整改

### 2.1 AC①／AC②：`core` 新增 `KdbxTags` 单一词汇表

`core/.../model/KdbxTags.kt`：`SEPARATORS = { ',', ';' }`（官方 `g_vTagSep`）、`WRITE_SEPARATOR = ";"`、`normalizeTag`（trim + 分隔符替换为 `.`）、`normalizeTags`（去空 + 去重 + **数字段感知自然排序**，`CompareNaturally` 同语义）、`parse`（切分 + 归一化）、`serialize`（归一化 + 裸 `;` 连接）。四个消费点全部接入：

| 消费点 | 整改前 | 整改后 |
|---|---|---|
| 读侧 `KdbxXmlGroupReader.parseTagsText`（条目 + 分组） | 只按 `;` 切、无归一化 | `KdbxTags.parse` |
| 写侧 `KdbxXmlEntrySerializer` / `KdbxXmlGroupSerializer` | `joinToString("; ")` | `KdbxTags.serialize`（裸 `;` + 归一化） |
| 编辑页 `EntryEditSaveProjection.parseEntryTags` | 按 `,` / `，` / 空格切 | `KdbxTags.parse`（不再按空格 / 全角逗号切——官方同口径，空格是合法标签字符） |
| 合并 `KdbxEntryMerger` 标签并集 | `distinct()` | `KdbxTags.normalizeTags`（同词汇归一化） |

### 2.2 AC③：写侧取舍写明

取「**写 `;`、读 `;` 与 `,`**」——与官方 KeePass 完全一致（`TagsToString(bForDisplay=false)` 裸 `;`；`StringToTags` 双分隔）。KeePassXC / pykeepass 以 `,` 写是读侧必须兼容的现实存量（本批读侧已兼容）；我方写侧不随它们用 `,`，理由是**官方为格式裁决者**（AGENTS.md 规则 3 优先级）。编辑页提示文案同步改为「用逗号或分号分隔」（中英成对）。

### 2.3 行为变化如实登记（波及面）

写侧两处真实变化：① `"; "` → `";"`；② 落盘标签经归一化（**排序 + 去重 + 分隔符换点**）。两处既有用例期望随之更正（`KdbxXmlFullRoundtripTest` 分组标签序、`KdbxTwofishRoundTripTest` 条目标签序），`KdbxTagsParseEquivalenceTest` 由「与旧表达式等价」改锁新口径（测试资产纪律①：只改期望未删用例）。
