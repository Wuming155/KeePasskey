# §367 云端打开对话框降噪与远端浏览接入批次（`ISSUE-P3-400` 整条闭环）

- **触发**：2026-09-30 用户安装 §366 debug 包真机走查反馈：「弹出的窗口无关信息太多……尤其是那些
  注释的提示，以至于根本没法选择远程文件路径。这里应该把其他地方的『加载远程路径』或者
  『选择远程路径』打开……还有兼容 S3 协议存储这一块也是，弹框不太合适，而且区域和存储桶并列
  在一起……它俩框的高度还不一样」。
- **开放项变动**：P3 区 1 → **0**（含搁置项 `ISSUE-P3-339` 归零前的最后一批）。

## 1. 问题定性

§366 把云端打开的凭据字段补齐时，三个体验缺陷同批引入 / 暴露：

1. **噪音挤占**：同步配置页的三段长 supporting 提示（坚果云 URL 提示 / WebDAV 专用密码说明 /
   远端路径说明）被原样搬进 AlertDialog——该容器本就被 8~11 个字段撑满，提示把远端路径字段
   顶到屏幕外不可达；
2. **只能手输**：远端路径 / Object Key 没有同步配置页已有的「浏览远端目录」能力
   （`RemoteBrowseController` + `RemoteBrowseSection`，ISSUE-P3-387/395/396 成果），
   用户不知道要填什么形态的路径——这恰是 §366 链路能否走通的关键字段；
3. **S3 双框不等高**：Bucket 与 Region 并列在半宽 `Row` 里，长 CJK 标签
   （「存储桶名称 (Bucket)」）在半宽内换行，把其中一框撑高一截。

## 2. 整改

- **去噪**：picker 表单删除全部 supporting 提示与密码 hint 文本（同步配置页文案**保留不动**，
  两处文案职责分野：picker 快速连接、设置页完整说明）；
- **浏览接入**：`OpenExistingVaultDialog` 增加 `browseState` / `onBrowseWebDav` / `onBrowseS3` /
  `onDismissBrowse` 通道，经 `DatabasePickerScreen` 透传 `DatabasePickerViewModel` 新增的
  浏览面（`remoteBrowseState` / `browseRemoteWebDav` / `browseRemoteS3` / `dismissRemoteBrowse`，
  复用设置页**同一** `RemoteBrowseController` 单例，**表单凭据优先**、无已保存回退——打开场景
  凭据本就在表单里）；WebDAV 表单远端路径下、S3 表单 Object Key 下各加「浏览远端目录」按钮
  （复用 `sync_browse_btn` 文案），开弹窗同时用表单凭据**发起首次列举**（浏览路径字段的父目录，
  与 `CloudSyncScreen` 同口径，复用 `parentDirectoryPath`）；点选文件回填 remotePath / objectKey
  并关闭浏览弹窗，此后「打开并加载」按所选文件走 §366 下载链路；浏览协程结束时擦除传入的凭据副本；
- **S3 双框等高**：picker 侧 Bucket / Region 改用与凭据字段（"Access Key ID" 等）同口径的
  短 ASCII 标签，半宽内不换行，两框高度恒等；
- **行数门禁配套**：`DatabasePickerViewModel`（399 恰满 tier2 边界）将 `KeyFileDeliveryState`
  迁至 `DatabasePickerUiState.kt` 并压缩数段历史 KDoc，浏览面加入后仍守 tier3。

## 3. 验收

- AC① picker 表单无 supporting 长提示；WebDAV / S3 均出现「浏览远端目录」入口，首次列举即出内容，
  点选文件回填路径字段，「打开并加载」按所选文件走 §366 下载链路（行为级由既有
  `RemoteBrowse*Test` 锁定控制器；对话框接线为 Compose 组合层，真机走查为最终判据）；
- AC② S3 的 Bucket / Region 两框等高（短标签杜绝换行）；
- AC③ 同步配置页浏览能力回归不破坏（其装配与文案零改动）；
- AC④ 全量 `test --rerun-tasks --max-workers=1` 绿 `xml=492 tests=3185 failures=0 errors=0
  skipped=13`（与 §366 基线持平——本批为纯 UI 接线，无新增单测）+ 门禁 8/8（§5）。

## 4. 过程留痕

- 初版接线漏了**首次列举触发**（只开弹窗不发起列举，浏览弹窗首屏为空——`RemoteBrowseDialog`
  对 `Idle` 渲染空）：对照 `CloudSyncScreen` 的 onBrowseRemote 闭包补上「开弹窗 + 表单凭据 +
  父目录」三合一触发，属 Compose 组合层缺陷，宿主单测不可达，以本留痕 + 真机走查承接；
- `DatabasePickerScreen` 的浏览状态形参初版误标为值类型（`RemoteBrowseUiState`），与 VM 的
  `StateFlow` 不匹配，改为 `StateFlow` + `collectAsState()` 收口；
- VM 399→424→399：浏览面 +41 行与 `KeyFileDeliveryState` 迁移、KDoc 压缩对冲，
  tier2 棘轮预算 37/37 保持恰满。
