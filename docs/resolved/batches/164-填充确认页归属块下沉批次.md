## 2. 为什么只搬这一块（同文件里还有 105 行的 `completeAuthResult`）

`completeAuthResult` / `showManualConfirm` 是**认证结果与凭据交付**的核心路径，被三处源码接线守卫锚定：

| 守卫 | 锚点 | 本批影响 |
|---|---|---|
| `AutofillAuthResultWiringTest` | 确认页必须真的 `readAutofillId(EXTRA_TARGET_USERNAME_ID / PASSWORD_ID)`；`RESULT_OK` 回传必须带 Intent 参数 | **不受影响**（判据在 Activity 本体） |
| `AutofillConfirmDeliveryLockTest` | 交付一次性锁（防重复 `setResult`） | **不受影响** |
| `ObscuredTouchWiringTest` | 敏感窗口根 Composable 首条语句必须调遮挡触摸过滤 | **不受影响** |

而该路径的**行为级**证据目前只有设备侧用例（`AutofillAuthChainDeviceTest`，§151 真机跑过、含锁屏与
`UiAutomation` 独占等环境前提）。本机无设备 ⇒ 搬它会进入「只能靠静态判据背书、无法真机复跑」的区域，
与本仓 `AGENTS.md` §5 的实跑义务精神冲突，故本批**不动**，把它的拆分留给能上真机的一段。
