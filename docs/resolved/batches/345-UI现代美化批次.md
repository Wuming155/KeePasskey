### ISSUE-P3-351：`tertiaryContainer` 覆写错位——palette 容器字段从未生效，tint 与底同色致图标淹没

- **优先级理由**：P3（视觉缺陷，非功能）；但它是「图标看不见」级别的可读性缺陷，且是
  `ISSUE-P3-348` 分色预览取像素时**实测照出**的（登记规则：发现新问题即时补登）。
- **核实时间点与方式（2026-09-28，方式：Pillow 取像素 + 读源码，非推定）**：
  `Theme.kt` `resolveAppColorScheme` 两个分支均写 `tertiaryContainer = themePalette.tertiaryColorLight/Dark`
  （**本体色的重复赋值**，palette 的 `tertiaryContainerLight/Dark` 字段从未被读取）；
  实测整改前条目行图标底（`VaultEntryRowLayouts.kt:160` tertiaryContainer）与图标 tint（tertiary）
  同为 `#6A5779` ⇒ **图标与底同色、肉眼不可辨**（最初截图中「预览站点登录」呈现为无图标的
  深紫实心方块即此因）；本批分色预览取像素 (0,105,110)=`#00696E`=tertiary 本体，复证同一错位。
- **整改口径**：两分支改为读 `tertiaryContainerLight` / `tertiaryContainerDark`（枚举字段本就存在）；
  受影响面 = 全仓所有 `colorScheme.tertiaryContainer` 读取方（条目行图标底、分组行 tile 等），
  颜色由「深色本体」回归「浅色容器」——正是 M3 container 语义。
- **AC**：
  ① 分色预览取像素：普通分组 tile ≠ tertiary 本体色，且 tint 与底对比 ≥ 4.5:1；
  ② 条目行图标（tertiary 容器底）图标重新可辨（预览图目检）；
  ③ `test` 全绿 + `gate_readings.py` 全 PASS。
- **关联**：`ISSUE-P3-348`（照出本条的现场）/ `Theme.kt` `resolveAppColorScheme`（落点）。

### ISSUE-P3-350：导航过渡未接 MotionScheme——NavHost 无显式 transition，切页手感与 Expressive 主题脱节

- **优先级理由**：P3（体验/动效，不涉功能与安全）；`MaterialExpressiveTheme` + `MotionScheme.expressive()`
  已在 `Theme.kt` 启用（TASK-07），但导航层未消费该基座，动效改造的最后一块拼图。
- **核实时间点与方式（2026-09-28，方式：读源码 + `gradle/libs.versions.toml`，非推定）**：
  `KeePasskeyApp.kt:372` 的 `NavHost(...)` 与 `KeePasskeyNavGraphRoutes.kt` / `KeePasskeySettingsNavGraphRoutes.kt`
  的全部 `composable(...)` **均未传** `enterTransition` / `exitTransition` / `popEnterTransition` / `popExitTransition`
  ⇒ 恒走 navigation-compose（2.10.1）库默认；`libs.versions.toml` 仅含 `navigation-compose`，
  未引入 `navigation-animation`（2.8+ 已不需要它，`NavHost` 自带过渡参数——**开工时先取 API 原文确认参数名与默认值，勿凭记忆**）。
- **整改口径**：
  - 在 `NavHost` 单点传入四个过渡参数：前进 = 水平 slide + fade、后退 = 反向 slide + fade，
    弹簧用 `spring(dampingRatio ≈ 0.8~1.0, stiffness 中低)`——禁止 `tween` 硬切，禁止给每个
    `composable` 逐个覆写（单点化，与 `resolveColorSource` 同思路）；
  - 弹簧参数与 `MotionScheme.expressive()` 的 `duration/expressiveDefaults` 口径保持一致
    （能从 motionScheme 取就从它取，不另造第二份手感常数）；
  - 不引入新依赖（2.10.1 自带能力足够，引 `navigation-animation` 属倒退）。
- **AC**：
  ① `NavHost` 四过渡参数齐备且为**单点设置**，仓内无第二份导航过渡配置；
  ② 前进与后退方向正确（前进新屏自右入、后退自左入，或统一采用「层级前进自右、返回自左」的对称口径），
     读数：人工走查解锁 → 列表 → 详情 → 返回，无反向穿帮；
  ③ 过渡为 spring 驱动（代码中不出现导航路径上的 `tween(`）；
  ④ `test` 全绿 + `gate_readings.py` 全 PASS + 截图包装编译过。
- **关联**：`Theme.kt`（MotionScheme 基座，TASK-07）/ `KeePasskeyApp.kt`（NavHost 落点）。

### ISSUE-P3-349：解锁页缺视觉锚点——顶部大面积空白、品牌区仅一枚静态小锁圆，首屏无「2026 感」

- **优先级理由**：P3（审美/首屏体验）；解锁页是每次打开 App 的第一眼，现状在 83 张截图中最"素"。
- **核实时间点与方式（2026-09-28，方式：`export-preview-main.bat` 导出截图逐张目检）**：
  `UnlockContent` 浅/深两态截图显示：顶部约 1/3 为空白，品牌区 = 浅蓝圆底 + 锁 icon + 标题 + 一行副标题，
  锁圆背后光晕为静态装饰；与设置页（彩色图标 tile）、健康页（评分环）相比无任何色彩锚点。
- **整改口径**：
  - 在品牌区加**静态渐变锚点**（如 primaryContainer → surface 的顶部渐变幕布、或品牌色几何弧形背景），
    覆盖顶部空白区；渐变取色**只能用现有语义令牌**（primary/primaryContainer/surface），禁止硬编码新 hex；
  - 可叠加锁圆的轻量入场动画（`AnimatedVisibility` / `animateFloatAsState`，一次入场，非常驻循环——
    常驻循环动画在解锁页停留时是持续 GPU 开销且与"安全工具"的克制气质冲突）；
  - 深色态同步设计（OLED 纯黑盘下渐变须仍可辨，`oledBlack` 分支不许糊成一团）。
- **AC**：
  ① 浅/深（含 OLED 盘目检）两态预览重导，顶部空白被锚点填充且不压暗输入区对比度；
  ② 颜色全部来自现有语义令牌（代码中无新增 `Color(0xFF...)`）；
  ③ 若加入场动画：一次性播放、非常驻循环，且 `@Preview` 静态帧完整可读；
  ④ 截图包装编译过 + `test` 全绿。
- **关联**：`UnlockContent` 预览（`preview-exports/main/{light,dark}` 对应图为整改前基线）。

  ③ 预览补例（至少含回收站 + 普通分组并排的 `@Preview`，遵守 `ISSUE-P3-340` 补态规则）；

### ISSUE-P3-347：surface 层级明度差过小——浅色卡片与背景仅差 ~3%，层次靠猜

- **优先级理由**：P3（审美/可读性）；「有颜色但不现代」的第二大根因：容器层级是 M3 表达层次的主手段，

  贴在背景上几乎不可辨；深色侧 `#101418 → #181C20` 同样只差约 4%。
  （`BentoCard` 注释已登记「描边会造成视觉杂音」的既有裁决 ⇒ 本条**只调 tonal 明度差，不加描边**。）
- **整改口径**：
  - 浅色：拉开相邻档到约 4~6% 明度差（如 low `#EDF1F7`、container `#E5EBF4`、high `#DCE3EE`、
    highest `#D4DCE9`——**最终值以导出截图目检 + 对 `onSurfaceVariant` 文本对比度复核为准**，
    文本对比度不得低于整改前）；
  - 深色：`surfaceContainerLow` 起各档同步微拉（卡片可辨即可，禁止拉成"灰块浮雕"）；
  - `OledDarkColorScheme` 各档同步等比调整（它 `copy` 自 `DarkColorScheme`，核对其手写档位）；
  - `OutlineLight` / 分隔线不动（ISSUE-P3-132 刚校准过，禁止回退）。
- **AC**：
  ① 相邻 surface 档明度差读数（hex → 相对亮度差）整改前后对照入批次文档；
  ② `onSurfaceVariant`（`#43474E`）对最深档 `surfaceContainerHighest` 的对比度 ≥ **6.0:1**

  ③ 亮/暗/OLED 三态截图重导目检，列表卡片与背景可辨；
