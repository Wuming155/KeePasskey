## 441.2 根因（M3 源码逐行核对 + 真机实证）

`SecurePasswordField` 用的是 `OutlinedTextField` 的 **String 重载**（无 `contentPadding` 参数）。
M3 的 `TextFieldMeasurePolicy`（`material3/internal/TextFieldImpl.kt`）：

1. `supportingIntrinsicHeight = supportingMeasurable?.minIntrinsicHeight(...) ?: 0`——**只要挂了
   `supportingText` 槽就计算**，与槽内有没有文案无关；该槽 Box 带 `heightIn(min = 16dp)` + 4dp 上间距 ⇒ **≈20dp**；
2. `textFieldConstraints = constraints.copy(minHeight = 0).offset(vertical = −(上内边距 + 下内边距 + supportingIntrinsicHeight))`
   ——正文与占位符共用这一组约束；无标签时 `contentPaddingWithoutLabel` = 上下各 **16dp**；
3. ⇒ 硬压 `.height(48.dp)` 时正文可用高度 = `48 − 16 − 16 − 20 = −4` ⇒ 钳到 **0**；
   占位符 Box 命中 `heightIn(min = 24dp)` 但被 maxHeight=0 钳回 0 ⇒ **正文区被压成 0 高度**。

（§438 猜测的「占位符标签 / 聚焦门控」机制**被证伪**：`placeholderOpacity` 在
`showExpandedLabel=false` 的 `UnfocusedEmpty` 态为 **1f**，本应可见；真凶是高度挤压。）

## 441.3 整改（AC②）

**取「解除 48dp 上限」**（`ISSUE-P3-472` AC② 列出的第三案）：

1. `UnlockVaultLayoutSections.kt`：去 `.height(48.dp)`；`supportingText` 改为**有文案才挂**
   （新增 `hasUnlockPasswordSupportingText(uiState)`，与 `UnlockPasswordSupportingText` 的四条渲染分支逐条对齐）。
   —— 条件挂载是**必须的配套**：空槽也白占 20dp，不条件挂载时行高会堆到 `16+24+16+20 = 76dp`；
   条件挂载后常态行高 = `16+24+16 = 56dp`（M3 `defaultMinSize(minHeight = 56.dp)` 同值），有提示时按需变高。
2. `SecurePasswordField.kt`：把该量纲契约写进 KDoc（**调用方必须保证行高 ≥ 56dp + supporting 槽固有高度**，
   否则正文区归零）——此前无任何注释提示这条 M3 约束。

**为何另两案不可行（留痕）**：

- 「字面量标签回归」：`label != null` 时标签参与 `effectiveTopOffset`，可用高度 = `48 − 16 − 标签高 − 16 − 20` **更负**，救不了；
- 「占位提示改为常显的提示行」：即便把提示移出字段，正文区 = `48 − 32 − 0 = 16dp`（**仍有 supporting 槽则为 −4**）
  ⇒ 低于 `MinTextLineHeight(24dp)`，**键入内容仍画不出**，等于只治了「提示可发现性」、留下更严重的「盲打」。
- 「保 48dp + 收窄上下内边距」：**编译期证伪**——String 重载**没有** `contentPadding` 参数
  （仅 `state: TextFieldState` 重载有），调用方拿不到该旋钮；改重载会动到本组件的「String 边界最小化」
  与擦除语义（`SecurePasswordField` 的 KDoc 契约），风险不成比例。

**与 §436 走查回执①「48dp 紧凑档」的相容性**：该回执的**目标**（字段别在分组卡里显高）保留，
**手段**（硬限高度）被证伪——它正是本缺陷的根因（M3 文本字段有硬性最小高度，低于此值即正文归零）。
代价如实登记：常态行高 **48dp → 56dp（+8dp）**。若日后要回到 48dp 观感，**可行路径只有**
①把该行的卡内上下外边距 10dp 收窄补偿，或 ②把组件换成 `TextFieldState` 重载 / 自绘 decorator
（后者触及安全擦除语义，须单独立项）。**本批未做**，因为用户当时选择的是「保 48dp」而该案不可实现，
改用上限解除属本批代理裁决，**可逆**（回退即恢复 48dp 硬压 + 原 unconditional 槽，缺陷同时回归）。
