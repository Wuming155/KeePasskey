## 2. 核心整改与架构收敛

### 2.1 4合1 一体化分组卡片（`UnlockVaultGroupCard`）
- 彻底移除 `UnlockAdvancedAuthCard` 嵌套折叠抽屉组件，将标准解锁页核心认证要素收敛为单张 M3 大圆角一体化卡片（`surfaceContainerLow` + 1dp `outlineVariant` 描边）：
  - **第 1 行**：活动数据库行（图标 + 库名与状态 + 右侧「切换 ❯」入口）；
  - **第 2 行**：内嵌扁平主密码输入框（`SecurePasswordField(embeddedFlat = true)`，密码显隐切换，条件挂载 `supportingText` 错误与节流锁定提示）；
  - **第 3 行**：密钥文件行（36dp 图标容器 + 标题「密钥文件」+ `● 已就绪` 状态微标 + 默认 `••••••••••••` 密码式掩码路径 + 密码式显隐眼睛按钮 + 独立清除按钮）；
  - **第 4 行**：只读打开行（36dp 图标容器 + 标题「以只读模式打开」与说明 + Material3 Switch 开关）。
- 各行之间采用 `start = 66.dp, end = 16.dp` 的统一内嵌分割线（`HorizontalDivider`），形成严整对齐的视觉中轴线。

### 2.2 KeePassDX 风格密钥文件路径密码框式掩码
- 对齐 KeePassDX `KeyFileSelectionView.kt` 交互规范：
  - 未展开状态下，路径文本呈现为 Monospace 字体的高安全感掩码点 `••••••••••••••••••••••••`（`letterSpacing = 2.sp`）；
  - 点击右侧眼睛图标切换显隐状态，展开呈现完整真实绝对路径并支持换行铺满；
  - 路径显隐切换按钮与文件清除按钮独立并列，互不干扰；未选密钥文件时右侧呈现优雅的 `KeyboardArrowRight` 引导箭头。

### 2.3 极速解锁（QuickUnlock）纯生物识别收敛
- 快速解锁界面维持纯净的 Class 3 强硬件安全密钥 `BiometricPrompt` 认证，彻底摒弃自研 PIN 键盘设计。
- `UnlockQuickUnlockReadOnlyCard` 移除冗余内部嵌套内边距，直接承载规范化 `UnlockReadOnlyRow`，整体界面视觉比例规整紧凑。

### 2.4 代码规模与结构门禁合规
- **函数长度门禁**（`long_functions.py`）：将 `UnlockKeyFileRowContent` 解耦拆分为 `UnlockKeyFileTextSection` 与 `UnlockKeyFileTrailingActions`，全仓函数均维持在 <100 行内。
- **行数棘轮预算**（`count_line_tiers.py`）：抽取独立段落文件 `UnlockKeyFileSourceSections.kt` 承载 `KeyFileSourceRow` 与 `abbreviatePath`，确保 `UnlockStandardUnlockSections.kt` 牢牢控制在 tier 3（<400 行），维持 `tier1=0` 且 `tier2=35 budget=35`。
- **单节点契约**（`check_box_slot_children.py`）：4合1 卡片采用线性 `Column` 顺序排布，彻底杜绝 Box 内容槽同层兄弟叠放风险。
- **提示位接线保护**（`HelpTipWiringTest.kt`）：更新 `UNLOCK_KEYFILE` 提示位扫描目标至 `UnlockVaultLayoutSections.kt`，测试全绿。
