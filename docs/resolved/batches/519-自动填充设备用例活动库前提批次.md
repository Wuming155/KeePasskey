- **核实时间点 + 核实方式**：2026-10-13；只读检查 seeder 与活动库解析，比较同一 APK 的有旧库/无旧库中文冷启动：前者停在解锁，后者完整通过。仅清除新建 AVD 隔离审计包的合成数据；没有更改代码。
- **背景 / 位置**：AutofillTestVaultSeeder.kt:43,47-50,69-71 写入 ac3 库，只记录其他库，不选定测试库；VaultDatabaseCatalog.kt:197-211,223-227 优先保留活动库；VaultLifecycleCoordinator.kt:60 打开活动项。

- **建议 / 验收**：使用独立测试安装/数据环境，或显式选择并断言播种库；不删除需保留的设备数据。覆盖已有活动库和首次安装，两者完整实跑并检查实际路径。
- **详细证据**：[动态软件审计](../../security/动态软件审计_2026-10-13.md)。

## 2. 实施与验收

- **前提复核（认领时，2026-10-14；直读 seeder / 用例 + 设备实跑）**：前提成立——`AutofillTestVaultSeeder.seed`
  只写文件即结束，**未**选择活动库；用例直接输入播种库主密码，活动库归属由目录扫描「首条 / 已保存选择」决定。
  方案声明的顺序依赖 `ISSUE-P3-607`（先修）已于 §508 前批次闭环。

- **改动一（播种器加固，方案步骤 1/2/6）**：`AutofillTestVaultSeeder` 重写：
  ①**写后当场校验**（签名前缀 + 可解 + 条目标题 / 数量一致）——落盘成功不等于内容正确；
  ②**不无条件删除同名库**：`isOwnedSynthetic` 以「可用测试主密码解开且含测试条目」判定归属，
  非本测试产物时**显式失败拒绝覆盖**；③新增 `seedDecoy`（**不同主密码**的合成干扰库，模拟设备上已有旧库）
  与 `deleteOwned` / `sha256`（供「旧库哈希不变」断言）；日志只记非敏感库身份与文件名。

- **改动二（活动库前提编排，方案步骤 3/4/5）**：新增 androidTest 辅助 `AutofillVaultSelection.kt`，
  经**生产 API**（`VaultRepository.getDatabases` / `selectDatabase`）选择并**断言**活动库——
  只改偏好不足以证明实际会话前提；并提供 `sessionPathIdentifier` / `sessionRootUuid` / `sessionEntryCount`
  读取解锁后**实际会话**。等待库列表落定（扫描在仓库构造期异步）避免静默空操作。

- **改动三（Hilt 入口落位）**：新增 main 源集 `di/AutofillDeviceGraph.kt`（`@EntryPoint`）暴露既有生产 API。
  **为何在 main**：Hilt 应用组件在编译期由 `@HiltAndroidApp` 生成，androidTest 源集声明的 `@EntryPoint`
  不在其生成范围——设备实跑首轮抛 `ClassCastException`（组件未实现该入口），据此把入口迁至 main。

- **改动四（用例前置与路径核验，方案步骤 3/4/5）**：`AutofillAuthChainDeviceTest` 新增：
  阶段 0.1 造干扰库（`withDecoy=false` 时不造，覆盖「无旧库」矩阵）；阶段 0.2 构造选择编排 →
  显式选择播种库 → **断言活动库 == 播种库** → 记录解锁前会话路径；阶段 5b 在真实解锁**之后**断言
  **实际会话路径含播种库文件名**、**会话条目数 == 1**、**干扰库 SHA-256 不变**；收尾恢复原活动选择并
  **只删本轮拥有的合成库**（`deleteOwned`，非本测试产物不动）。矩阵参数：`appLanguage`（`ZH_CN` / `EN_US`）
  与 `withDecoy`（`true` / `false`）经 instrumentation 参数注入。

- **设备实跑（方案 §4 矩阵，AVD `kp-256`，API 36）**：四组合各一轮完整执行，均 `BUILD SUCCESSFUL`，
  单例 `tests=1 failures=0 errors=0 skipped=0`：
  | 轮次 | appLanguage | withDecoy | 结果 |
  |---|---|---|---|
  | 1 | ZH_CN | true（已有不同密码旧活动库） | PASS |
  | 2 | ZH_CN | false（首次安装无旧库） | PASS |
  | 3 | EN_US | true | PASS |
  | 4 | EN_US | false | PASS |
  每轮均通过「前置断言活动库 == 播种库」与「解锁后会话路径 == 播种库 + 条目数 1 + 旧库哈希不变」，
  即**路径级证据**（不再把「清空后通过」当成路径已确证）。
  命令：`./gradlew.bat :app:connectedDebugAndroidTest -Pandroid.testInstrumentationRunnerArguments.class=com.keepasskey.app.autofill.AutofillAuthChainDeviceTest -Pandroid.testInstrumentationRunnerArguments.appLanguage=<ZH_CN|EN_US> -Pandroid.testInstrumentationRunnerArguments.withDecoy=<true|false>`。
