## 1. ISSUE-P3-396：浏览仅根目录可开 / 无法同步

### 1.1 根因（两处叠加）

| # | 缺陷 | 后果 |
|---|---|---|
| A | 控制器对**一切** `remotePath` 做 `parentDirectoryPath()`：下钻 `Passkeys` → 父目录为空串 | 点击文件夹无法进入；分页续拉同样被拆回根 |
| B | PROPFIND href 为**绝对路径**（如 `/remote.php/dav/files/user/vaults/…`）时未剥离端点 path，直接与 `buildUrl` 再拼一次 | 得到重复路径 → 404 → 无法下钻 / 选中后同步失败 |

### 1.2 整改

- `WebDavDirectoryList.relativeResourcePath`：完整 URL / 绝对路径（剥 `serverUrl` path 前缀）/ 相对集合三形态；
- `RemoteBrowseController.browseWebDav/browseS3` 的 path 参数语义改为**要列举的目录本身**（不再取父）；
- UI：初始选库用 `parentDirectoryPath(remotePath)`；下钻传 `entry.path`；分页传 `directoryPath`。

### 1.3 验收

- AC① Nextcloud 形态绝对 href 相对化后不重复 `remote.php`（`WebDavBrowsePathResolutionTest`）；
- AC② 下钻路径直接生效（控制器不再拆父，`RemoteBrowseParentPathTest`）；
- AC③ 同步所用路径与浏览选中路径一致（路径归一同一套函数）。

## 2. ISSUE-P3-397：并入后点击库闪退

### 2.1 根因

`KdbxMerger` 对单侧独有对象**复用对端 `ProtectedString` 实例**；`KdbxMergeController` 在 `finally` 里对第二库调用裸 `otherDb.clearSensitiveData()` ⇒ 会话树仍在引用的字段被清零 ⇒ 投影/打开时 `ProtectedString.checkNotCleared` 抛 `IllegalStateException`（`SECURITY_RECHECK_2026-09.md` §9.6 #19 同型）。

### 2.2 整改

与 `SyncConflictAutoMerge` / `SyncConflictMergeAdjudication.eraseDiscardedDatabase` **同一口径**：

- 采用后存活侧 = 会话树；只擦不被存活树以同一实例引用的敏感缓冲；
- 未采用路径存活侧 = 原本地库；只读/无库路径仍全量擦（尚无存活别名）。

### 2.3 验收

- AC① 并入后对端独有条目仍可读标题/密码（`MergeSharedProtectedStringWipeTest`）；
- AC② 不得再调用裸 `clearSensitiveData` 擦除第二库（源码判据：合并 finally 走 `eraseDiscardedDatabase`）；
- AC③ 全量 `test` 绿 + 门禁 8/8。
