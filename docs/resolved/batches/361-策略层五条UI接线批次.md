## 1. 整改内容

### 1.1 `ISSUE-P2-379` 前台闲置自动锁定 UI

- `SecuritySettingsScreen`：安全设置页自动锁定区新增「前台闲置自动锁定」开关 + 超时档 `SecurityChoiceChips`；关闭态显示风险说明；`@Preview` 两态覆盖。
- `SettingsViewModel` / `SettingsIssueWiring`：`setAutoLockForegroundEnabled` / `setAutoLockForegroundTimeoutSeconds` 单语句委托至 `SettingsDatabaseMetaController`。
- `KeePasskeySettingsNavGraphRoutes`：回调接线。
- 中英文案：`sec_fg_lock_*`（4 键）。
- 行为侧（`AutoLockManager` 前台调度 / `ForegroundIdleLockPolicy`）本批零改动。

### 1.2 `ISSUE-P2-378` 外部修改检测接线

- **基线留存**：`VaultFileBaselineHolder`（@Singleton + 锁观察者）；`VaultLifecycleCoordinator` 打开成功后 `capture`；`RealVaultRepository` 构造期 `register()`。
- **保存时点**：`persistSession` 调用 `VaultFileDriftCoordinator.checkDrift` → 漂移即 `Failure(ext_mod_save_aborted)` + 唤起待决提示，禁止静默覆盖。
- **回前台时点**：`AutoLockManager.onStart` 增加 `addOnForegroundResumeListener`（供探测与漂移提示挂点）。
- **三选处置**：`VaultFileDriftResolve`（自 `RealVaultRepository` 拆出）——放弃 / 重载（克隆会话凭据后 open）/ 合并（`KdbxMerger` 三方 + `adoptDatabaseIfUnchanged` + save）；失败保留内存改动并上浮文案。
- **UI**：`ExternalModificationDialog` + `ExternalModificationDialogHost` 挂在 `KeePasskeyApp`；`SettingsViewModel.externalModificationPending` 转发。
- 中英文案：`ext_mod_*`（8 键）。

### 1.3 `ISSUE-P3-381` 回前台 / 网络恢复远端探测

- `ResumeSyncProbeCoordinator`：进程回前台（`AutoLockManager` 监听）+ `ConnectivityManager` 网络回调；策略层 `ResumeSyncProbePolicy` 门控（开关 + 30s 节流 + 锁定态跳过）；**不直接 syncNow**。
- `SyncCoordinator`：`resolveRemotePathForProbe` / `lastRemoteEtagForProbe` / `rememberRemoteEtagForProbe`；`SyncSessionState.lastRemoteEtag`。
- `MainApplication`：冷启动 `resumeSyncProbeCoordinator.initialize()`（`autoLockManager.initialize()` 之后）。
- 设置页：安全设置区「回前台探测远端变化」开关。
- 中英文案：`sec_sync_probe_*` / `sync_probe_*`（5 键）。

### 1.4 `ISSUE-P3-382` 健康检查重复条目只读报告

- `SettingsHealthController`：扫描时调用 `scanDuplicates` 通道，产出 `duplicateGroupCount` / `duplicateEntryCount`。
- `HealthCheckScreen`：审计区新增「重复条目」计数行（未扫描中性 / 有重复需注意 / 无重复通过）。
- 合并语义不变：只读报告；用户在条目编辑/删除管线逐条处理，**不与同步 `KdbxMerger` 混用**。
- 中英文案：`health_duplicate_*`（5 键）。

### 1.5 `ISSUE-P3-385` 库级 Meta 编辑 UI + defaultUserName 预填

- `DatabaseSettingsComponents`：库名 / 描述 / 默认用户名三行可点击进入编辑；新建条目预填说明。
- `DatabaseMetaEditDialog`：三项可编辑对话框，保存经 `setDatabaseMeta` → `SettingsDatabaseMetaController` → `updateDatabaseMeta` + 立即 `save`（PD-35 合并语义「以本地为准」不变）。
- `SettingsUiState` / `DatabaseConfigUiState` / 投影 / `SettingsPreferencesController`：新增 `databaseDescription`。
- `EntryEditViewModel`：新建路径（无 entryId / templateId）预填库 `defaultUserName`（搜索词预填不冲突）。
- 中英文案：`dbset_meta_*` / `dbset_field_db_desc` / `dbset_new_entry_prefill_hint`（7 键）。
