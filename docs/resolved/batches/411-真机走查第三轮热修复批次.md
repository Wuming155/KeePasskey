## §1 整改内容

### 1.1 `ISSUE-P3-447` AC① 收口：SAF 库可云同步（条目保持开放，剩 AC②③）

- **用户回执**：「下滑提示『当前无打开的密码库文件』未解决」。核实：§410 的 `isSyncConfigured()` 预检方向正确但前提错——走查库**已配置** WebDAV 云同步（用户此前测试「本地库同步到云端」），`isSyncConfigured()` 为 true，进入同步周期后在 `SyncCycleRunner.runSyncCycle` 首行 `currentFile ?: Error(sync_error_no_open_vault_file)` 早退（SAF 库 `associatedFile == null`）。
- **整改**（同步周期对本地文件的唯一依赖是「远端路径默认名」，本地字节恒由内存树序列化而来，故以库名兜底即可让 SAF 库进入同一周期）：
  - `SyncCycleRunner.runSyncCycle`：先取 `currentDb`（未解锁错误语义不变），`vaultFileName = currentFile?.name ?: "${currentDb.databaseName}.kdbx"`；删除 `no_open_vault_file` 早退分支；
  - `SyncCycleRunner.takeoverVaultBinding`：同口径改写；
  - `SyncCycleSetup.setupCycleContext(activeFile: File)` → `setupCycleContext(vaultFileName: String)`，`resolveRemotePath(vaultFileName)`；
  - `SyncCoordinator.resolveRemotePathForProbe`：`currentFile?.name ?: databaseFlow.databaseName 兜底`（原 `?: return if (isSyncConfigured()) null else null` 恒 null 死代码一并消除）——解锁后自动重同步探测同样覆盖 SAF 库。
  - 库身份绑定 / 缓存 / 防回滚键（rootGroup UUID 命名空间）与本地库同构不变；首传基线（`establishRemoteBaselineIfMissing`）只依赖 provider，无本地 File 依赖。

### 1.3 截屏限制语义修订（用户裁决 2026-10-02，推翻 2026-09-12「锁定态无条件强制」半环）

- **用户回执**：「已经关闭了截屏限制，解锁密码库界面依然无法截屏」。根因＝`FlagSecurePolicy.shouldApplySecure = sessionLocked || userEnabled`，解锁页会话恒 LOCKED ⇒ 恒强制。
