# §368 云端打开展示名默认取远端文件名批次（`ISSUE-P3-401` 整条闭环）

- **触发**：2026-09-30 用户安装 §367 debug 包真机走查反馈：「密码库展示的名称没有默认值，
  应该默认使用远程文件路径对应的文件名称」。
- **开放项变动**：P3 区 2 → **1**（仅剩搁置项 `ISSUE-P3-339`）。

## 1. 问题定性

「密码库展示名称」为空且必填，但远端路径（WebDAV remotePath / S3 objectKey，含 §367 接入的
浏览点选回填）本身就携带文件名（如 `mailbox/keepasskey.kdbx`）——展示名要求用户把同一个
信息重复敲一遍，纯冗余输入。

## 2. 整改

- 表单状态类（`WebdavVaultFormState` / `S3VaultFormState`）增加展示名推导：
  `applyRemotePath` / `applyObjectKey` 在路径变化（手输或浏览点选回填，两者已收敛为同一入口）
  时若展示名**未被用户手动编辑过**，自动取路径末段文件名（`remoteFileName`，去首尾斜杠取
  末段）作为默认值；`editName` 记录手动编辑标记（**清空视为放弃手动值**，此后路径变化恢复
  自动推导）；状态 `init` 即按默认路径推导，打开对话框便有默认名；
- 字段绑定改走上述方法（Sections / FormBody 浏览点选回填同步），路径字段仍存用户完整输入值，
  只有展示名取末段。

## 3. 验收

- AC① 填入 / 点选远端路径后展示名自动为路径末段文件名（含初始默认路径推导）；
- AC② 用户手动改过展示名后路径再变不覆盖；清空后恢复推导（`OpenVaultFormStateTest` 4 例，
  `mutableStateOf` JVM 直读写）；
- AC③ 全量 `test --rerun-tasks --max-workers=1` 绿 `xml=493 tests=3189 failures=0 errors=0
  skipped=13`（§367 基线 492/3185 ⇒ +1 xml/+4 例）+ 门禁 8/8（§5）。

## 4. 过程留痕

- 首轮全量 1 红：新测试自身断言写错（对 `remotePath` 断言了末段文件名——路径字段应存用户
  完整输入值，派生的只是展示名），修正测试后绿；产品代码零改动。
