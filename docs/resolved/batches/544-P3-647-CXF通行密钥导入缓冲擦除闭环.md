# §544 ISSUE-P3-647 CXF 通行密钥导入缓冲擦除闭环

## 范围

闭环 `ISSUE-P3-647 CXF通行密钥导入遗留UTF-8工作字节与JSON副本`。本批将生产代码、适用 JVM 测试、敏感缓冲所有权契约、独立整改方案、当前问题台账和归档索引一起更新。

2026-10-18，用户确认系统相册导入成功即可满足本项设备验收。相册路径将虚构 CXF 凭据送入与扫码路径共用的 `PasskeyImportDraftHost`，覆盖本项修复的 UTF-8 工作数组、解析 AST 与草案交付生命周期。

## 实际整改

- `PasskeyImportDraftHost.begin` 将 UTF-8 工作数组保存到局部变量，在解析器成功、拒绝或异常后均通过 `finally` 擦除；编码器内部字节数组也由 `finally` 清零，原始 `CharArray` 仍由入口统一清理。
- `ByteSink` 实现确定性关闭清理，扩容替换时清除旧数组；JSON 字符串解析的成功与失败路径均关闭临时 sink。扫描失败清理已分配的字符串节点，扫描成功后把 AST 清理责任交给调用方。
- `PasskeyCxfReader.read` 在所有正常与异常终态递归擦除 AST 字符串节点，包括重复键、未知成员、未选凭据及失败分支。交付给 `ImportedPasskey` 的 PEM / PRF 是独立数组，调用链按既有契约负责擦除。
- `docs/architecture/敏感缓冲所有权契约.md` 增加 Passkey 导入所有权条目，标明入口、扫描器、读取器和调用方的清理边界。
