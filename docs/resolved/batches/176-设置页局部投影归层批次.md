## 2. 为什么是"归层"而不是"新建文件"

`SettingsUiStateProjection.kt` 的定位就是「设置页 UI 状态的**纯投影层**：不持有状态、可脱离
ViewModel 独立推理与测试」，而 `databaseConfigFromHeader` 正是同一类东西（ISSUE-P2-19 / P3-59 的
「以活动库文件头为单一真相源」映射），三个 data class 又是它的输入/输出类型。
再开一个 `*Projections2.kt` 只会把同一层劈成两处——包内已有权威归属时，**搬进既有文件优先**。

因全部搬动都在**同一 package 内**（`app.ui.screens.settings`），`internal` 可见性与
`DatabaseConfigUiState` 等类型的**全限定引用（含 `CipherLabels.kt`、`SettingsViewModel`）零改动**。
