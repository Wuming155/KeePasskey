## 436.1 整改内容

新布局（STANDARD 完整解锁路径）＝品牌区〔方形锁块 + 呼吸点 → 标题 → 状态胶囊〕→
**分组卡**〔数据库行 + 内部分隔线 + 扁平主密码行〕→ **「高级认证凭证」折叠卡**
〔密钥文件提示条 / 密钥文件行 / 只读开关行〕→ 底部〔解锁主按钮 + QuickUnlock 次级胶囊按钮〕。

- 新增 `UnlockVaultLayoutSections.kt`：`UnlockDatabaseRow`（icon 块 + 名称/状态 + 「切换」尾标，
  整行与尾标两个手势入口都走切换库导航）、`UnlockVaultGroupCard`（Surface extraLarge +
  outlineVariant 描边 + 内部分隔线缩进 66dp）、`UnlockPasswordSupportingText`（自
  `UnlockContentSections.kt` **逐字迁出**，`private` → `internal`，渲染语义零变化）、
  `UnlockStandardUnlockContent`（迁出并重排为上述布局；新增 `databaseRow` 槽与
  `advancedExpanded` / `onToggleAdvancedExpanded` 状态外提参数——ISSUE-P3-340 口径）。
- `UnlockContentSections.kt`：`UnlockVaultLogo` 重绘为**方形锁块**（64dp / shapes.large /
  surfaceContainerLow 底 + outlineVariant 描边）+ 右下 primary **呼吸点**
  （`rememberInfiniteTransition`，受 `LocalReduceAnimations` 降级偏好裁决，降级时只保留实心点）；
  新增 `UnlockAdvancedAuthCard`（折叠卡，默认展开＝功能可见性与改版前一致）与

  `Text` 重绘为**状态胶囊** `UnlockStatusPill`（点 + 文案）；降级文案选择逻辑
  （`uiState.quickUnlockDowngraded` / `R.string.unlock_quick_subtitle_software`）逐字保留在原文件。

- `SecurePasswordField.kt`（向后兼容扩展）：`label` 放宽为可空（`null` = 不渲染浮动标签）；
  新增 `embeddedFlat: Boolean = false` 扁平形态——四态描边与容器全透明，字段以「无边框行」
  嵌入分组卡。默认 `false`＝既有外观，既有调用点（条目编辑 / 改密对话框等）零变化；
  `semantics { password() }` 与 `KeyboardType.Password` 显式声明原样

## 436.2 守卫与锚点

- 逐字保留：`UnlockEmptyEntryWiringTest`（`UnlockScreen.kt` 两处 `onNavigateToDatabasePicker()`
  改由分组卡数据库行的整行点击 + 尾标点击承载）、`HelpTipWiringTest`
  （`HelpTip.UNLOCK_KEYFILE` 留在 `UnlockContentSections.kt`）、`UiMd3AlignmentWiringTest`
  （`disabledPrimaryButtonColors()` / `disabledPrimaryButtonBorder()` 留在
  `UnlockStandardUnlockSections.kt`）、`SecurityClaimWiringTest`（降级文案锚点）、
  `SecurePasswordFieldSemanticsWiringTest`。
- **tween 豁免登记**（`AppNavigationMotionTest.TWEEN_EXEMPT_FILES` 新增
  `UnlockContentSections.kt`）：呼吸点是**常驻氛围动效**（1.8s 循环，时长收敛到具名 token
  `AppNavigationMotion.UNLOCK_PING_CYCLE_MS`）——循环「淡出-归零-重启」必须由确定时长 +
  线性缓动表达，spring 无法构成该循环，motionScheme 三档 spec 是转场短时长、语义不匹配；
  与导航转场时间轴无关，故文件级豁免（非「为让守卫变绿而加名单」，理由如上）。
