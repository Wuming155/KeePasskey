# §180 文档相对链接断链收口批次（`docs/resolved/batches/` 26 处指向不存在的相对路径）

> **起因**：§179 顺带发现「自己写的索引行把链接截断成 `](batches/178-)`」，遂把「文档里的相对链接
> 到底指不指得到文件」这件事**变成可复核判据**（新增 `tools/doc/check_md_links.py`），
> 而不是只修自己那一处。首跑即暴露一类**系统性**旧缺陷：**26 处**相对链接解析失败，
> 全部落在 `docs/resolved/batches/`（19 份文件）。
>
> **根因**：批次正文里写链接时按「相对 `docs/`」的口径（`architecture/已知工程限界.md`、
> `../architecture/…`、`records/…`），但 Markdown 的相对路径**以本文件所在目录为基准**——
> 批次正文住在 `docs/resolved/batches/`，少两级 `../../` ⇒ 从写下那天起就是断链，
> 只是此前没有任何工具检查过（`AGENTS.md` §4「索引纪律」要求登记，未要求可跳转）。

---

## 1. 改动

| 对象 | 内容 |
|---|---|
| `tools/doc/check_md_links.py` | 新增：遍历 `docs/**/*.md`，按 Markdown 语义（相对**本文件**）判定每个 `](xxx.md)`；断链则退出码 1 并给出「目标实际位于何处」的建议路径 |
| 19 份 `docs/resolved/batches/*.md` | 26 处链接改写为正确的相对路径（`architecture/…` → `../../architecture/…`、`../architecture/…` → `../../architecture/…`、`records/…` → `../../records/…` 等）。**逐文件 diff 均为 `+N/−N` 行内替换**，只动括号内的路径，正文一字未改 |
| `AGENTS.md` §4 / §5 | §5 命令表登记该自检（并登记 `count_line_tiers.py` 为行数唯一口径）；§4「索引纪律」补一句「登记的链接**必须可跳转**」，使纪律有可执行的判据 |

## 2. 两类必须先排除的假阳性（决定了工具口径）

首版扫描报 **30** 处，其中 **4 处是误报**，全部位于 ```markdown 围栏代码块内：

- `docs/security/第四轮复核遗留编号处置.md` §8「建议索引行」三段——那是**供主控粘贴到
  `docs/README.md` / `RESOLVED_LOG.md` / `BATCH_158_PLUS.md` 的正文**，其路径按**目标文件**的体例书写
  （`resolved/batches/…` 对 `RESOLVED_LOG.md` 正确、`batches/…` 对 `BATCH_158_PLUS.md` 正确）；
- `docs/security/待复核区IPC与SUPPLY项重合声明核实.md` 里一段被整体围栏的引用文字同理。

⇒ 判定与修复**一律跳过围栏代码块**（口径写进脚本文档串）。若不改口径，「修断链」会反过来
**破坏这些引用正文的保真度**——这正是 §3「不得为凑绿而放宽」的另一面：先证明判据本身可信。

**第二类误报是本批自己的正文招出来的**：写完本批次文档再跑自检，报 2 处断链，
都是**放在行内代码里的示例**（`` `](xxx.md)` ``、`` `](../architecture/已知工程限界.md)` ``——
§1 / §3 用来说明「什么叫断链」）。⇒ 口径再加一条：**行内 `` `code` `` 片段一并剔除**；
剔除后链接目标仍可命中（形如 `[`docs/x.md`](../y.md)` 的写法里，目标本就在反引号之外）。
最终：**修前 26 → 修后 0**，且工具的两次口径收紧都是**减少报告项、不放过真断链**
（真断链的定义始终是「非代码区里的 `](…md)` 指向不存在的文件」）。

另核 `docs/**/*.md` 的围栏**奇偶性全部配对**（无未闭合围栏掩盖真链接的情况，实测见 §4）。

## 3. 修的是链接，不是内容

被改的 19 份文件都是**已归档批次正文**。本批**只改括号内的路径**：
`](../architecture/已知工程限界.md)` → `](../../architecture/已知工程限界.md)` 这类，
结论、数字、表格结构一律不动 ⇒ 归档语义不变，只是**从「点开 404」变成「点开能看」**。
