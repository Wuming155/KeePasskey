## 4. 标签 / 收藏接线的实现要点（AC③）

- **过滤逻辑全部在状态层**（对齐本页「状态层装配、UI 只绘制」约定）：`VaultListFilterParams` 增 `selectedTag` / `favoriteOnly` 两参数（与搜索防抖流同流下发）；`selectSortedEntries` 的过滤合取式扩为 `matchesSearchQuery(...) && (!favoriteOnly || it.isFavorite) && (selectedTag == null || selectedTag in it.tags)`——筛选与搜索是**两个独立合取项**，空查询不旁路筛选档。
- **候选装配**：`buildAvailableTags` 对全库条目标签做**精确值**去重（KDBX 标签区分大小写，选中档须与 `tags` 精确匹配才可命中）+ 大小写不敏感排序；`hasFavoriteEntries = allEntries.any { it.isFavorite }` 作为「收藏」芯片可见性判据。
- **会话态口径**：筛选档与排序同口径（`MutableStateFlow` 会话态、不持久化、切换目录不清除）；`VaultListScreen` 以稳定 key 渲染芯片行，回收站内不呈现。
- **守卫**：新增 `VaultListProjectionFiltersTest` 8 例——无筛选不过滤 / 收藏档 / 标签档 / 两档叠加 / 空白查询下筛选仍生效 / 候选精确去重 + 不敏感排序 / `hasFavoriteEntries` 判据 / 无标签候选空表。
- **既有测试零改动**；`VaultListViewModelTest` / `VaultListProjectionSearchTest` 原样通过。
