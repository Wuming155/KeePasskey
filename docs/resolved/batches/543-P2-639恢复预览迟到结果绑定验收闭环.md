## 范围

闭环 `ISSUE-P2-639 恢复预览迟到结果未绑定所选副本`。修复、适用测试、当前台账和归档同批更新；独立整改方案保留在 `docs/architecture/问题整改方案/P2/ISSUE-P2-639/整改方案.md` 作为历史方案与验收说明。

## 实际整改

`RecoveryViewModel` 为成功预览保存非敏感绑定凭证，包含 vault id、正式库路径、恢复 payload 文件名/长度/SHA-256 和单调请求代次。请求完成时复核请求代次、当前选择及最新 pending 身份，不匹配或已失效的结果不写入状态。选择切换、刷新、keep 会清除或失效预览；busy 时 UI 行与 ViewModel 入口均阻止切换和重复预览。恢复入口及覆盖确认后的二次调用要求凭证仍匹配当前副本。

生产预览仍委托 `VaultRecoveryCoordinator.preview`；内部可替换的 suspend 操作只用于确定性屏障测试。
