## 2. 为什么这次动手前先做了「等价性指纹」

§188 的收敛前提是「这几处的配色与 insets **逐字相同**」，而该前提当时是靠**目测五页一致**登记的。
本批把这条前提做成**可复跑判据**：新增 `tools/doc/scaffold_block_fingerprint.py`——
按括号配平取出每页的 `Scaffold(...)` 块，**只归一化掉骨架已以参数承载的三项**
（标题资源、`snackbarHost` 行、尾随 lambda 形参名），其余取 SHA-256 前 12 位分组。

对 §188 之前的十个页面实跑（`python tools/doc/scaffold_block_fingerprint.py 5690ecf^ …/subscreens <十页>`）：

| 指纹 | 页数 | 成员 | 与其它桶的**实质**差异 |
|---|---:|---|---|
| `b747a601984c` | 6 | About / Theme / Autofill / Security / HealthCheck / DatabaseSettings | — |
| `bd8e31ac9d28` | 3 | Totp / Debug / CloudSync | 仅多一行 `snackbarHost`（已归一化 ⇒ 桶内差异为 0） |
| `78e95ad7d0ea` | **1** | **PrivilegedBrowserSettingsScreen** | `topAppBarColors(containerColor = background)`、**且无** `titleContentColor` |

⇒ 本批五页与 §188 已替换的四页同桶（差异只有标题与 snackbar 两项，均由骨架参数承载），
**替换是等价的**；而 §188 唯一跨桶替换的那一页正是被「目测」误判的一页 ⇒ 见 §3。

## 3. 登记 `ISSUE-P3-195`：§188 改掉了 `PrivilegedBrowserSettingsScreen` 的顶栏配色

- **症状**：该页顶栏 `containerColor` 由 `MaterialTheme.colorScheme.background` 变成骨架写死的 `surface`，
  并新增了原块没有的 `titleContentColor = onSurface`。浅色主题下 `background` 与 `surface` 极接近，
  深色主题下可辨 ⇒ 属**真实呈现变更**，非纯搬家。
- **成因**：§188 §2 写「实测五页这两项逐字相同（这正是收敛的前提）」——**该结论对其中四页成立、对这一页不成立**，
  当时未做 §2 的指纹比对。
- **两条修法与阻塞情况（务必如实读）**：
  ① 给骨架加 `topBarContainerColor` / `topBarTitleContentColor: Color?` 两个可空参数（默认值复刻其余九页，
  该页传 `background` / `null`）——**改动被拦**，理由属未经确认的设计变更；
  ② 该页退回自写 `Scaffold + TopAppBar`（纯撤销 §188 对它的那一次替换，可空参数不加）——
  **同样被拦**（同一判据）。⇒ **本批未改任何生产代码**，只登记条目并留下指纹判据，交由用户择一。
- **本批不擅自选②的理由**：撤销会让「10 份收敛为 1 份」变成 9 份，与该页出第 3 目表（115→95）的既成收益纠缠，
  两条路的**取舍口径不同**（参数化 = 骨架继续长大；退回 = 骨架保持最小但留一处例外），属产品/工程偏好而非机械修法。

## 4. 守卫锚点核实（替换前逐页做过）

五页的守卫判据**全部命中原样保留的正文**，无一落在被删的 26 行块内 ⇒ 本批**未新增任何并集扩扫**
（剩余清单第 3 项的「搬家必须同批改并集」在本批是**空操作**，这本身就是锚点位置核实的结果）。
判据是**反向的**：若有一条锚在被删块内，`test --rerun-tasks` 会当场失败（§160 的三测试类同时失配即此形态），
而全量套件为绿 ⇒ 五页的锚点确实都在块外。

- `DebugSettingsScreen`：锚点 `val coloredLines = remember(logLines) {`（§188 §4 已核在块外，本批复核仍在）；
- `DatabaseSettingsScreen`：`ExportTicketSinkGuardTest` 锚在四个 `CreateDocument` launcher 与 `pending…Uri` 上（正文中段）；
- 其余三页锚在 `LazyColumn` 正文的开关 / 按钮行上。
