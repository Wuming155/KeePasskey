# §378 空密码不判弱密码批次（`ISSUE-P3-408` 整条闭环）

> **触发**：2026-09-30 用户命题「空密码你怎么能判定为弱密码呢？空密码说明就不需要密码」，并建议对照 KeePassXC 密码强度检测口径。
> **结案条目**：`ISSUE-P3-408`（整条闭环）。

## 0. 原文登记（用户命题 + 核实）

> **ISSUE-P3-408**（核实时间点 2026-09-30；核实方式 = 用户命题 + 代码审计 + 仓内参考文档）：空密码不得计入弱密码审计。
>
> - **核实方式**：用户明确「空密码说明就不需要密码」；`HealthCheckEngine` §377 后仍对**非 passkey** 空密码产出 `WEAK`；`docs/references/KeePassXC-架构分析.md` 对 `PasswordHealth.cpp` 只登记「弱密码/重复审计」，**未写空密码语义**；`参考项目/` 禁止无目标扫描源码，故本条不以 KeePassXC 为唯一判据，以**用户产品裁决**为准。
> - **背景**：空密码常见于通行密钥、仅备注/资料类条目——语义是「本条目不需要密码」，不是弱密码。强度评估只应针对**已填写**的口令。
> - **整改**：
>   1. `HealthCheckEngine`：`password == null || length == 0` **一律**不产出 `WEAK`（含普通条目）；
>   2. 强度评估只在口令非空时执行；EXPIRED / REUSED 不变；
>   3. 单测：空密码不报 WEAK；弱口令仍报 WEAK。
> - **验收**：空密码条目不进入弱密码明细；门禁全 PASS。

---

## 1. 根因与整改

### 1.1 根因与与 §377 的关系

§377 只豁免「带 passkey schema 键」的空密码；普通条目空密码仍被标为弱密码。用户进一步裁决：**空密码一律不需要密码，不进弱密码审计**——故删除 passkey 特判，统一为「空密码早退、不评强度」。

### 1.2 与 KeePassXC 对照（如实）

| 项目 | 本批口径 |
|---|---|
| 仓内参考文档 | `PasswordHealth.cpp` 仅登记弱/复用审计入口，**无**空密码语义条目 |
| 参考项目源码 | 按 AGENTS 禁止无目标扫描，本批**未**读 KeePassXC 实现 |
| 本产品裁决 | **空密码 ≠ 弱密码**（用户 2026-09-30 明示） |

若日后需严格对齐 KeePassXC 某版本行为，应另开条目并**先读** `docs/references/` 对应文档 + 有目标取证，不得在本条上悄悄改回。
