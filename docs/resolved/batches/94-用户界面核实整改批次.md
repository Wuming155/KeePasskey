## §94 用户界面核实整改批次（2026-09-16）

> **本批次缘起**：用户报告一批 Compose 界面问题（布局裁切 / 交互逻辑 / 视觉一致性 / 中英混排），
> 逐条对照生产源码核实后**属实者当场整改**；不属实项如实留痕不改。
> **未走 ACTIVE_ISSUES**：问题在本轮已闭环，故只写本归档（不入待办表）。

### 94.1 核实结论与整改对照

| 用户报告 | 核实 | 整改 |
|---|---|---|
| 多页底部裁切（主设置 `System` / 安全策略 `Clipboard` / 外观 `Obsidian` / 同步 `Offline cache`） | **属实**——edge-to-edge 下 `LazyColumn`/`Column` 缺系统导航栏 inset | 主设置 / 安全 / 外观 / 同步 / 健康度 / 生成器补 `navigationBarsPadding()`；密码库列表 `contentPadding.bottom=96.dp` 预留 FAB |
| 健康度仪表盘 `82` 下 `Overall health score` 换行重叠 | **属实**——英文长文案塞进 96dp 圆 | 分数只留圆内，标签移到圆外 |
| 密钥文件用 Toggle Switch | **属实** | 改为选择行：未选 hint+箭头；已选文件名+勾选（再点清除） |
| `UNLOCK VAULT` 未输入密码仍可点 | **属实** | `UnlockUiState.hasPassword`；无密码且无密钥文件时禁用 |
| 生成器顶 `Very strong (112 bits)` vs 强度条 `Moderate (96 bits)` | **属实，根因阈值不一致** | `PasswordStrengthBar` 对齐 `GeneratorViewModel`（`≥96/≥64/≥40`）；`GeneratorUiState` 默认自洽为 96 |
| 未验证时 `Sync now` 仍高亮可点 | **属实** | 新增 `isConnectionVerified`；测试连接/同步成功才置位；未验证禁用并中性徽标；配置变更复位 |
| 默认排序下 Reset 常亮 | **不属实**——仅非默认排序显示 `SortStatusHint` | 不改 |
| 回收站无已删条目数 | **属实** | 横幅增加 `vault_recycle_bin_count` |
| TOTP 验证码与 Copy 同行易误触 | **属实** | 整行不再可点，仅右侧复制按钮（`defaultMinSize` 48×40） |
| 外观页主题卡片 vs 调色盘 RadioButton 混用 | **属实** | 调色盘改为与主题模式一致的勾选角标 |
| FAB 阴影不足 | 部分属实 | 显式 `elevation=6.dp` |
| 深色设置图标对比不足 | 部分属实 | 深色下图标容器 alpha `0.12→0.28` |
| 安全页 Switch+Chevron 混用 | **设计意图合理**（二元 vs 多选导航） | 不改结构 |
| `syncStatusText="未验证"` / `GZip 压缩` 中文硬编码 | **属实**（前者生产路径从不覆盖） | 资源化 `sync_status_unverified`；压缩算法改 `GZip` |
| 解锁/健康度等 `@Preview` 中文样例 | 属实（仅 IDE 预览） | 预览样例改英文 |

### 94.2 主要改动面

- `SecurityBadge.kt`：强度条四档阈值与 ViewModel 对齐  
- `GeneratorUiState.kt`：默认 `entropyBits`/`strengthLabel` 自洽  
- `HealthCheckScreen.kt`：仪表布局 + 底部 inset  
- `UnlockUiState.kt` / `UnlockViewModel.kt` / `UnlockContentSections.kt`：`hasPassword`、密钥文件行、解锁按钮禁用  
- `SettingsUiState.kt` / `SettingsSyncController.kt` / `SettingsUiStateProjection.kt` / `CloudSyncComponents.kt`：连接验证状态闭环  
- `ThemeSettingsComponents.kt` / `SettingsComponents.kt`：选中语义统一、深色图标容器  
- `AuthenticatorScreen.kt`：TOTP 复制热区收窄  
- `VaultListScreen.kt` / `VaultListComponents.kt`：底部 padding、FAB elevation、回收站条目数  
- `strings.xml` / `values-en`：`sync_status_unverified`、`vault_recycle_bin_count`
