### ISSUE-P2-617：Autofill 记忆条目未绑定当前网站来源

- **发现**：`csf_25353e9278ce47be1b59afc9`
- **位置**：`app/src/main/java/com/keepasskey/app/autofill/AutofillUnlockedCandidates.kt`、`AutofillCallerEntryMemory.kt`、`AutofillCandidateRanker.kt`、`AutofillConfirmActivity.kt:291`
- **触发**：用户此前在某网站确认填充后，恶意网站在相同浏览器/签名下请求 Autofill；调用方记忆按包名与签名召回条目，候选排序绕过当前域匹配，且已信任调用方的生物识别提示不显示当前网站。
- **后果**：用户仍需选择建议并再次完成认证；认证后的最终交付路径也未复检条目与当前域的匹配，其他网站可能收到原网站密码或 TOTP。不能将此描述为静默泄露。
- **建议**：浏览器网站凭据记忆必须绑定已验证域名；不得让包级记忆绕过网站来源匹配；在最终交付前复检来源，并在认证提示中显示当前域。
- **严重度/置信度**：P2 / 高。
- **核实时间与方式**：2026-10-15；基于 revision `8eed1507f5b6013986d715577d8f8a355fb9bdaf` 的静态源码调用链审查，未做设备验证。

### ISSUE-P3-616：外部 Provider 元数据查询可能阻塞主线程

- **发现**：`csf_5467b1a7862232e8e7291a47`、`csf_ed7bb236d2c3481e4cde7625`
- **位置**：`OpenVaultEntryActivity.kt`、`ui/screens/database/DatabasePickerScreen.kt`、`OpenExistingVaultDialog.kt`、`CreateVaultWizardDialog.kt`
- **触发**：外部应用调用 exported 文件入口并提供其 Provider 的 URI；或用户在 SAF 选择器中选中由缓慢/恶意 Provider 提供的文档。相关路径同步执行 `ContentResolver.query` 并读取 Cursor。
- **后果**：KeePasskey 主线程等待外部 Provider，可能出现 ANR。SAF 入口需用户先选择文档；导出入口的查询发生在确认 UI 前。
- **建议**：将元数据查询移到受控 IO 调度器并接入取消机制；URI scheme 已先校验，仍须避免主线程等待外部 Provider。协程超时本身不能证明底层 Binder 调用已中断。
- **严重度/置信度**：P3 / 高。
- **核实时间与方式**：2026-10-15；静态检查 manifest 导出属性、Activity 调用顺序和 SAF 回调；未做 ANR 设备复现。

### ISSUE-P3-617：外部文件流在大小限制前整块读入内存

- **发现**：`csf_127dc5cc161a0e85a2821165`、`csf_af9de3d732f53520d973722`
- **位置**：`VaultFileDriftResolve.kt`、`ui/screens/edit/EntryEditPickers.kt`、`database/file/KdbxFile.kt`
- **触发**：用户确认合并外部变化，或选择附件/自定义图标；代码对本地文件/SAF 流先调用 `readBytes()`，附件和图标路径仅在整流后检查实际长度。未知或错误申报长度可绕过读取前检查。
- **后果**：超大输入在解析器或导入限制生效前分配完整 `ByteArray`，可能导致 OOM/ANR。
- **建议**：使用带硬字节上限的分块读取；对未知长度同样执行累计上限，超限立即停止并清理缓冲。
- **严重度/置信度**：P3 / 高。
- **核实时间与方式**：2026-10-15；静态追踪 drift merge、附件/图标导入和 KDBX 限制的先后顺序；未做设备 OOM 复现。

### 同批加固 P2-618 / P2-619（非 ACTIVE 登记项，工作区既有实现随本批归档）

- **P2-619**：文件体积闸门只约束总字节数，逗号密集行仍能在允许体积内生成海量字段对象——`CsvRecordReader` 在字段对象分配前按 `ImportLimits.MAX_FIELDS_PER_RECORD = 256` 拒绝（超限 fail-closed，上界 256 可通过）。

## 2. 实施与验收

- **P2-617（记忆绑定已验证域名）**：`AutofillCallerEntryMemory` 记忆键由「包名 + 摘要」扩展为「包名 + 摘要 + 归属域」（读写同归一口径，旧无域键自然不可达、由容量上限淘汰）；`resolveUnlockedCandidates` 召回传入归属校验后的域（表单自报域不得作为记忆键）；`AutofillCandidateRanker` 浏览器上下文的记忆条目须过当前域匹配（纯 App 上下文仍不经匹配，共用判据下沉 `AutofillDeliveryOrigin.kt`）；确认页生物识别副标题并入归属校验后的目标域（无域如实标注纯应用表单），最终交付前以同源判据复检（`resolveConfirmAuthResultIntent`，缓存重放 fail-closed）；选择器/确认页两处写入点分别绑定表单域/已校验域。旧键格式升级说明见 `AutofillCallerEntryMemory` KDoc。
