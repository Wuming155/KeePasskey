## 1. 闭环条目正文

### ISSUE-P2-588：部分搜索框聚焦时误唤出自动填充/解锁引导弹窗（京东等应用搜索页）

- **背景与根因（五处叠加缺陷导致搜索框被捕获为填充目标并下发解锁引导）**：
  1. **搜索框识别维度缺失**（`AutofillFieldScanner.kt` 与 `AutofillFieldLexicon.kt`）：未识别 Android 规范过滤/搜索变体 `InputType.TYPE_TEXT_VARIATION_FILTER`（`0xb0`）；未提取与检查 ViewNode 的 `className`（如 `SearchView` / `SearchAutoComplete` / `SearchEditText` 等组件）；未提取与检查 `contentDescription`；词表缺少高频中文动词“搜”（“搜商品”、“搜回收”等）、“查找”、“检索”，英文子串词表缺少 `find`、`filter`；导致商品推荐词 hint 无法被识别为搜索框。
  2. **`htmlName` 错误回退导致属性污染**（`AutofillStructureScan.kt`）：`val htmlName = node.idEntry ?: node.hint`。将提示文案 `hint` 误当作 `htmlName` 传入后续匹配，若 hint 中含有普通英文词（如 phone、user、passport 等），会被 `isUsernameHtmlName` / `isPasswordHtmlName` 误判为账号或密码信号。
  3. **`isPasswordHtmlName` 过度泛化**（`AutofillFieldScanner.kt`）：`n.contains("pass")` 过于松散，误将大厂鉴权组件（如京东 `JDPassport` 的 `passport` 类 idEntry）、`passenger`、`compass`、`bypass` 等误判为密码框，且不可见密码框被直接准入。
  4. **`synthesizeFocusedUsername` 越界合成**（`AutofillFieldFallback.kt`）：当后台或深层视图存在不可见的伪密码候选时，聚焦字段补齐未校验密码框的可见性，直接将前台用户正在聚焦的搜索框合成为 `usernameId`。
  5. **缺乏单账号字段下发门控**（`AutofillTargetFieldResolver.kt`）：当表单中无密码框时，弱账号信号（LOW 或普通文本）亦未被拦截，缺乏 KeePassDX 式的表单有效性强门控。
- **涉及文件**：
  - `app/src/main/java/com/keepasskey/app/autofill/AutofillScanModels.kt`（新立模型文件，抽出 `FieldConfidence` 与 `ScanNode`，行数门禁健康分流）
  - `app/src/main/java/com/keepasskey/app/autofill/AutofillStructureScan.kt`
  - `app/src/main/java/com/keepasskey/app/autofill/AutofillFieldScanner.kt`
  - `app/src/main/java/com/keepasskey/app/autofill/AutofillFieldLexicon.kt`
  - `app/src/main/java/com/keepasskey/app/autofill/AutofillFieldFallback.kt`
  - `app/src/main/java/com/keepasskey/app/autofill/AutofillTargetFieldResolver.kt`
  - `app/src/test/java/com/keepasskey/app/autofill/AutofillFieldScannerTest.kt`
  - `app/src/test/java/com/keepasskey/app/autofill/AutofillFieldFallbackTest.kt`
  - `app/src/test/java/com/keepasskey/app/autofill/AutofillAuthResultRecheckWiringTest.kt`
- **整改要点**：
  ① **多维识别与词表扩充**：`ScanNode` 增设 `className` 与 `contentDescription`；`isSearchField` 纳入 `TYPE_TEXT_VARIATION_FILTER`、`SearchView` 等类名、`contentDescription` 搜索描述；词表补齐“搜”、“查找”、“寻找”、“检索”、“find”、“filter”等动词与子串。
  ② **阻断 hint 属性污染**：`AutofillStructureScanner` 废除 `node.idEntry ?: node.hint`，严格取 `idEntry` 或 HTML 属性 `extractHtmlName`，null 时保持 null，不以 hint 污染变量标识符匹配通道。
  ③ **收紧密码名称匹配**：`isPasswordHtmlName` 显式排除 `passport`、`passenger`、`compass`、`bypass`、`passage` 等非密码词。
  ④ **密码框可见性强门控**：`synthesizeFocusedUsername` 严格限制必须密码框处于可见状态（`isVisible == true`）才允许进行聚焦账号补齐，阻断后台控件对前台聚焦框的越界捕获。
  ⑤ **单账号字段安全准入门槛**：对齐第一参考项目 KeePassDX（`isValid(): passwordId != null || ...`），无密码框时账号字段必须满足 `HIGH` 置信度（显式 autofillHints）或明确账号 inputType（邮箱/电话），弱账号信号在无密码框时绝不下发填充响应。
  ⑥ **单测覆盖与守卫锁定**：新增针对过滤变体、SearchView 类名、无障碍描述、动词搜索词、非密码排除、不可见密码框合成禁止、单账号字段门控的完整测试集。
