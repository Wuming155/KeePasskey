## 4. 过程缺陷（如实登记）

1. **§200 漏了两处归档登记**：① `docs/resolved/README.md` L31 的「当前最大编号」是唯一维护处，
   §200 结案推送时未同步（仍写 §199）；② `RESOLVED_LOG.md` 的全量批次索引漏加 §200 行
   （只登了分册 `BATCH_158_PLUS.md`）。两处均由本批收尾自查纠出、随本批一并补齐——
   归档收尾自此固定为三查：全量索引行、分册行、编号指针。
2. **`PasskeyCryptoEngineTest` 的包名与文件位置错位**（历史布局，本批不改）：
   文件在 `crypto/src/test/java/com/keepasskey/crypto/` 下而包名是 `com.keepasskey.crypto.passkey`，
   按 `--tests com.keepasskey.crypto.PasskeyCryptoEngineTest` 过滤会**静默匹配零用例**且 Gradle 仍报
   `BUILD SUCCESSFUL`（只要过滤器整体有命中）——首次定向验证因此漏跑该套件，第二次以正确包名补跑
   （14 例全绿）。定向跑测后**必须回读 `TEST-*.xml` 确认用例在册**，不能只看 BUILD 字样。
