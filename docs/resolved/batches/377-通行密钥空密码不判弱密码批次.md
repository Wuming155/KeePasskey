# §377 通行密钥空密码不判弱密码批次（`ISSUE-P3-407` 整条闭环）

> **触发**：2026-09-30 用户真机反馈「存在一个问题，尤其是通行密钥没有密码，这种情况下也会将空密码识别为弱密码」。
> **结案条目**：`ISSUE-P3-407`（整条闭环）。

## 0. 原文登记（用户命题 + 核实）

> **ISSUE-P3-407**（核实时间点 2026-09-30；核实方式 = 用户真机反馈 + 代码审计）：通行密钥空密码被健康检查误判为弱密码。
>
> - **核实方式**：用户反馈通行密钥条目无传统密码，却被健康检查判为弱密码；代码审计 `HealthCheckEngine.analyzeEntry` 对 `password == null || length == 0` **无条件**产出 `WEAK`，未区分 passkey 条目。
> - **背景**：通行密钥（WebAuthn / KPEX）以自定义字段承载私钥与 rpId，**本无传统密码**；空密码是正常形态，不得计入弱密码审计。
> - **整改**：
>   1. `HealthCheckEngine` 在空密码分支前用**形状短路**（仅扫自定义字段键名，不解密、不物化 String）识别 passkey schema 键；
>   2. 命中 passkey schema 键 ⇒ **跳过**「空密码 = 弱密码」误报；非 passkey 空密码仍判 WEAK；
>   3. 有密码的 passkey 条目仍走既有强度评估；EXPIRED 时效检查不受影响；
>   4. 单测锁定 passkey 空密码不报 WEAK、普通空密码仍报 WEAK。
> - **验收**：含 passkey schema 字段且无密码的条目不进入弱密码明细；相关单测与 `gate_readings.py` 全 PASS。

---

## 1. 根因与整改

### 1.1 根因

`HealthCheckEngine.analyzeEntry` 空密码分支无条件 `WEAK`，未区分通行密钥。KPEX 通行密钥本无 `Password` 字段，健康检查将其误报为弱密码。

### 1.2 整改落地

| 点 | 变更 |
|---|---|
| `HealthCheckEngine.hasPasskeySchemaFields` | 形状短路：扫 `customFields` 键名是否命中 `PasskeyData.isPasskeyFieldKey`（KPEX / v1 / 扩展），**不解密** |
| 空密码分支 | 命中 passkey schema ⇒ 跳过 WEAK；未命中 ⇒ 仍报「未设置密码或密码为空」 |
| 不变面 | 有密码条目仍评强度；EXPIRED 在密码分支之前仍检查；普通空密码仍 WEAK |

口径选择：**任意** passkey schema 键即视为 passkey 相关条目（含半成品仅 RP 键），避免半成品通行密钥被空密码误报。
