## 2. 实施与验收

- **前提复核（认领时）**：直读确认前提成立——`persistSession` 是唯一带漂移检查的落盘出口；`SettingsPreferencesController`
  的 `setEncryptionAlgorithm` / `setKdfAlgorithm` / `setArgon2Parameters` / `setRecycleBinEnabled`、
  `SettingsDatabaseMetaController.setDatabaseMeta` 与 `VaultLifecycleCoordinator.changeMasterPassword` /
  `changeKeyFileOnly` 均**直连** `DatabaseSession`（`updateDatabaseMeta + save` / `changeCredentials`），
  绕过漂移检查。

- **改动一（统一提交边界，新增 `VaultWriteBoundary.kt`）**：把「库身份 / 会话修订（漂移检查）→ 候选变换 →
  落盘 → 基线刷新」收口为单一可测类：
  - `abortOnDrift()`：写前外部修改漂移检查（fail-closed，命中即返回可上浮失败并唤起三选提示）；
  - `persist()`：会话落盘**唯一出口**（挂锁成对 + 成功后刷新文件基线 + 失败日志回调）；
  - `commitMeta(transform)`：库级元数据候选提交，次序固定为「**先漂移检查 → 再应用候选 → 再落盘**」。

- **改动二（窄接口 `VaultWritePort`）**：新增库级写入意图窄接口（`commitDatabaseMeta`，默认安全失败），
  `VaultRepository` 继承之，接口方法全限定名与既有调用点零改动。

- **改动三（仓库接线，`RealVaultRepository`）**：`persistSession` / 漂移检查实现整体收敛到 `VaultWriteBoundary`
  （逐行等价搬迁）；`commitDatabaseMeta` 委托 `writeBoundary.commitMeta`；`VaultLifecycleCoordinator` 经
  `driftRejection = ::driftAbortFailure` 注入与全库保存**同源**的写前漂移判据。

- **改动四（设置控制器只提交意图）**：`SettingsPreferencesController` 四个 setter 与
  `SettingsDatabaseMetaController.setDatabaseMeta` 改经 `vaultRepository.commitDatabaseMeta { ... }`，
  **不再**直接调用 `session.updateDatabaseMeta / save`；相关 KDoc 的过时陈述同步更正。

- **改动五（换密 / 改绑写前检查）**：`VaultLifecycleCoordinator.changeMasterPassword` /
  `changeKeyFileOnly` 以 `driftRejection() ?: when (...) {...}` 形式在**进入凭据重加密前**先做漂移拦截
  （零净增行数的等价改写）。

- **测试（新增 2 个用例类，共 5 例）**：
  - `VaultWriteBoundaryDriftTest`（4 例）：① 外部修改 ⇒ `commitMeta` fail-closed、**不应用**意图（内存树不变）、
    外部文件字节原样保留、三选提示唤起；② 无漂移 ⇒ 提交真实落盘且基线刷新后二次提交不误报；
    ③ 单一出口 `persist` 同源 fail-closed；④ 换密 / 改绑入口在漂移时**先拒绝**（返回同一失败实例、各检查一次）。
  - `SettingsWriteBoundaryRoutingTest`（1 例）：设置控制器**只经统一边界提交**（记录型替身），
    替身不落盘时会话树保持不变 ⇒ 锁死「不直连会话写」。
  - 既有 `AlgorithmSelectionApplyTest`（6）/ `Argon2ParametersApplyTest`（2）/ `RecycleBinToggleApplyTest`（4）/
    `VaultCreationCancellationTest`（1）经统一边界后全绿（替身 `FakeVaultRepository` 增可选 `databaseSession`
    使「设置真实落盘」契约在替身上同样成立）。

- **全量单测**：`./gradlew.bat test --max-workers=1` EXIT 0；`count_test_results.py` 读数
  **`xml=575 tests=3752 failures=0 errors=0 skipped=15`**（§512 基线 3747 ⇒ +5）。
