> **ISSUE-P3-416**：安全架构 / 零知识同步 / TOTP 引擎三张说明卡迁入「关于」页。
>
> - **状态（2026-10-01 登记，同日认领整改）**：进行中。
> - **核实时间点**：2026-10-01。
> - **核实方式**：用户装机验证 §382 时以三张真机截图直报「这些内容放错位置了，应该放到关于里面」——①安全设置页「安全架构说明」卡（`sec_arch_desc` 164 字）；②TOTP 设置页说明卡（`totp_info_desc` 153 字）；③同步设置页「零知识端到端加密」卡（`sync_zeroknowledge_desc` + 凭据封印条件文案）。
> - **根因**：三卡是「背景知识 / 机制解释」型长内容，按 §382 的三层裁决属「info 层」，但其宿主（安全 / TOTP / 同步设置子页）是操作面——参考项目口径里操作面不放机制长文；「关于」页才是产品自述面（已有「技术规格」段 + 隐私声明卡同型内容）。
> - **整改方案**：三卡**迁**（非复制，红线＝设置项单一位置）入「关于」页「技术规格」段之后：①安全架构卡与 TOTP 说明卡在 `AboutSettingsScreenSections.kt` 新建等形 composable（复用原字符串资源，TOTP 卡补标题 `totp_info_title` 中英 ×2）；②零知识卡直接复用 `CloudSyncSections.kt` 的 `ZeroKnowledgeCard`（同包 internal，含 P2-285 实测条件渲染语义原样）；③三个设置子页摘除对应 item 挂载点；④`SecurityClaimWiringTest` 对 `ZeroKnowledgeCard` 宿主的源码断言同步指向 `AboutSettingsScreen.kt`（语义不变、消费链不变，非放宽）；⑤`SyncCredentialSealer.kt:40` KDoc 宿主指针同步更正。
> - **涉及文件**：`SecuritySettingsScreen.kt` / `TotpSettingsScreen.kt` / `CloudSyncScreen.kt`（摘挂载）、`AboutSettingsScreen.kt` / `AboutSettingsScreenSections.kt`（挂载）、`strings.xml` ×2（+1 键 `totp_info_title`）、`SecurityClaimWiringTest.kt`、`SyncCredentialSealer.kt`（仅 KDoc）。
> - **验收标准**：AC① 三个设置子页不再渲染三卡，「关于」页按序呈现（技术规格 → 安全架构说明 → 零知识端到端加密 → TOTP 引擎说明 → 隐私声明）；AC② P2-285 实测条件渲染链路（探测 → 控制器 → 投影 → UiState → 卡片）逐环不变；AC③ 全量 test 绿 + 门禁 8/8；AC④ 装机 debug 包经用户确认。
