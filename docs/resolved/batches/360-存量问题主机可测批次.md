## 4. 过程缺陷与边界

1. **误覆盖 `AutofillWebDomainPolicy`**：拆分混域策略时曾误写同名文件，覆盖了既有归属校验内核；经 `git checkout` 恢复后改名 `AutofillDomainConsistencyPolicy`。教训：同包已有同名对象时拆分必须先检索。
2. **行数门禁**：`count_line_tiers` 一度 tier1=2 / tier2=38；经拆出 `EntryCustomDataMerge` / `EntryMergeHelpers` / `SettingsDatabaseMetaController` / `AutofillFieldLexicon` / `TotpUriTextCodec` 后 tier1=0、tier2=37/37。
3. **热路径守卫测试**：`AlgoHotPathGuardsTest` 原断言正则在 `AutofillFieldScanner` 文件内；随拆分改断言 `AutofillFieldLexicon`，并禁止 scanner 本体残留副本。
4. **如实未做**：
   - KeePassXC `steam://` 逐码对拍（本机无 `keepassxc-cli` 二进制）；
   - `P2-378` / `P2-379` / `P3-381` / `P3-382` / `P3-385` 的 Compose UI 接线；
   - `P3-384` / `P3-387` 大特性；
   - 设备侧 / `-DliveSyncTest` / `assembleRelease`（用户指示本批不依赖真机）。
5. **`P3-385` AC② 新建条目默认用户名预填**：写通道与 Meta 字段已就绪，`EntryEditViewModel` 预填未接线，条目保持开放。
