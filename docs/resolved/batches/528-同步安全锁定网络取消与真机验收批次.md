# §528 同步安全锁定网络取消与真机验收批次

<a id="s528"></a>

## 1. 闭环范围

本批关闭 ISSUE-P2-625。慢 HTTPS 请求原先可让同步子任务在自动锁定时继续等待网络，扩大明文会话与主凭据的驻留时间。

## 2. 实施与验收

- 同步网络阶段不持有自动锁挂锁；安全锁定观察器取消同步及冲突、覆盖、备份子任务，WebDAV/S3 将协程取消传至活动 OkHttp `Call.cancel()`。
- JVM 锁定、取消、排队和 412 用例通过；Redmi 4X API 37 上 WebDAV/S3 回环取消设备用例通过。
- Redmi 4X API 37 使用 debug-only raw trust anchor 和本地受控生产 HTTPS WebDAV。慢 MOVE 在途时，真实熄屏广播与 app 后台超时各触发一次锁定；锁定请求到 `DatabaseSession.LOCKED` 在 5 秒预算内完成，活动上传不报告成功，正式 KDBX 以主密码重开并确认预先落盘的 revision B 保全。
- 在条件 MOVE 返回 HTTP 412、后续元数据请求被延迟期间触发后台锁定，设备用例通过；服务端回执确认 race 已触发，远端 revision C 未被 revision B 覆盖。
- 非空设备 XML：`.ci-artifacts/remediation-20261015/p2-627/slow-screen_off-lock-SyncSlowHttpsScreenOffLockDeviceTest.xml`、`slow-background-lock-SyncSlowHttpsScreenOffLockDeviceTest.xml`；HTTP 412 交错回执：`http-412-race-e00789db17b4.triggered`。用例通过后恢复锁定偏好和设备屏幕状态。
- `DatabaseSession.lock()` 在发布 `LOCKED` 前清除主密码/密钥文件凭据缓存并销毁数据库明文树；设备用例观察 `LOCKED` 后成功以测试主密码重开正式文件。

## 3. 限制

- 5 秒是本整改的正常设备验收预算，不承诺 Android 操作系统调度的硬实时上界。
- 设备覆盖 Redmi 4X API 37；更大数据库、不同 Android 厂商和操作系统版本仍可能有不同的本地文件提交耗时。
