# §396 移除新建云端直建批次（用户裁决：新建只保留本地两档，会话内整改随批归档）

> **触发**：2026-10-01 用户在 §395 实现态装机走查后反馈：「算了，新建密码库没必要新建云端，
> 就本地的两个就可以，把云端去掉。」
> **结案条目**：会话内整改（未占 ISSUE 编号），随本批次文档归档。

---

## 0. 裁决与影响面

- **裁决链留痕**：ISSUE-P3-425（§391）引入「云端直建」（filesDir 建库 + 云 syncType 幂等重登记，
  未配置账号置灰禁选）→ §395 改「恒可选 + 创建按钮禁用」→ **本批整条移除**。三天内两改并非
  反复：§395 的「没法选择」投诉与 §396 的「干脆去掉」都是用户真机体验后的主动收敛，最终口径
  为——**新建云端库的需求由「打开已有库」的云端导入 + 既有同步周期覆盖，向导只保留本地两档**。
- **影响面（核实 2026-10-01，全仓 grep）**：`VaultStorageLocation.CLOUD` 枚举值、
  `CloudSyncSnapshot` 数据类、VM `createDatabase` 的 `storageLocation` 形参与 fail-closed 分支、
  `registerCloudCreatedVault`、控制器快照消费面（`cloudSnapshot` / `cloudReady` /
  `cloudSyncTypeLabel` / `refreshSnapshot` / `computeSnapshot`）、向导与宿主的
  `cloudSnapshot` 透传、7 条字符串（zh/en 成对）——**全部无残余消费者**（「打开已有库」的
  云端导入 `CloudVaultImporter` / 预填 / 远端浏览不受影响，原样保留）。
