# §542 P2-637 前台闲置锁定与 P3-653 品牌配色验收闭环

## 范围

本批闭环两项已登记问题：

- P2：637，前台闲置锁定旧定时任务无法取消且使用陈旧设置。
- P3：653，切回品牌调色盘未清除残留自定义种子色。

两项分别保留独立整改方案，均在代码、定向测试、当前问题台账和本批归档中收口。

## 实际整改

| 问题 | 改动与验收 |
|---|---|
| P2-637 | 抽出 `ForegroundIdleLockTimer`，保存单一任务句柄并用代次校验使替换、关闭、锁态和后台时的旧协程失效；到期重新读取最新设置并检查生命周期。虚拟时钟用例覆盖关闭、延长、缩短、连续交互重排、后台取消和重新解锁。Android 设备用例经生产 `AutoLockManager.onUserInteraction()` 触发立即锁库，确认锁事件到达、正式 KDBX 字节未变，并以新 `DatabaseSession` 解密确认已提交条目仍存在。 |
| P3-653 | 品牌来源操作在单次 DataStore `edit` 中关闭动态取色并清除 seed，保留已选 palette；导航、ViewModel 和偏好控制器接线。状态转换和源码接线用例通过。Android 设备用例经生产 `RealSettingsRepository` 写入、重建仓库后回读确认 palette 保留、dynamic 关闭、seed 清除。 |
