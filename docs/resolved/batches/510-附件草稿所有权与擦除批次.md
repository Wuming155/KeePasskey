### ISSUE-P2-600：附件草稿缺少锁定、移除和替换时的所有权与擦除闭环

- **整改方案**：[ISSUE-P2-600 独立方案](../../architecture/问题整改方案/P2/ISSUE-P2-600/附件草稿所有权与擦除方案.md)；方案已编制，尚未实施。

- **核实时间点 + 核实方式**：2026-10-13；现行调用链与相关测试直读。仅审计，未整改。
- **背景 / 位置**：`EntryEditPasswordGenerator.kt:76-95` 持有新附件字节且丢弃旧引用不清理；`EntryEditViewModel.kt:480-499` 锁定/销毁清理未含附件；`AttachmentMergePolicy.kt:31` 与 KdbxAttachment 零拷贝还共享数组。
- **触发 / 后果**：导入敏感附件后锁库/放弃编辑/替换同名附件；明文草稿仍存活或等待 GC。保存后草稿与库共享数组，不能直接填零以免破坏库。
- **建议 / 验收**：先明确草稿与会话各自拥有的缓冲，交接采用安全所有权协议；只擦除仍由草稿拥有的字节，覆盖保存后锁定不损坏附件、未保存草稿锁定/移除擦除。
- **详细证据**：[全面软件审计](../../security/全面软件审计_2026-10-13.md)。

## 2. 实施与验收

- **前提复核（认领时）**：直读确认前提成立——`EntryEditAttachmentDraft.add` 同名替换 `filterNot{fileName}` 后直接
  丢引用不清零；`remove` 同型；`AttachmentMergePolicy.merge` 对 `ui.data != null` 直接 `KdbxAttachment(data = ui.data)`
  （会话与草稿**共享**借用视图）；`EntryEditViewModel.clearAllSecrets` 未含附件草稿。

- **改动一（草稿独占擦除，`EntryEditPasswordGenerator.EntryEditAttachmentDraft`）**：新增 `state` 读取口。
  `add`（同名替换）与 `remove` 在退出 UI 态后擦除被淘汰的**草稿自有**数组（`data != null`）；
  清零副作用刻意置于 `update` 闭包**之外**（`StateFlow.update` 可能重试，闭包须纯粹）。
  新增幂等 `wipeDrafts()`：锁定 / 销毁时擦除全部草稿自有数组并从 UI 态移除草稿（库内投影 `data == null` 不动）。

- **改动二（会话独立副本，`AttachmentMergePolicy.merge`）**：`ui.data != null` 分支改为 `ui.data.copyOf()`——
  会话侧持独立副本，避免落库后编辑页在锁定 / 销毁时清零草稿数组而**一并清零库内附件**
  （`KdbxAttachment.data` 内存来源为借用视图）。不改 `KdbxAttachment` 的零拷贝契约。

- **改动三（接锁定 / 销毁清理，`EntryEditViewModel.clearAllSecrets`）**：新增 `attachments.wipeDrafts()`，
  与既有 `databaseSession` 锁定守卫 / `onCleared` 共用同一清理点。

- **测试（新增 2 类 6 例）**：
  | 用例类 | 覆盖 | 判别力 |

  | `AttachmentDraftOwnershipTest`（5） | 同名替换 / 移除 / 锁定擦草稿；库内投影不擦；空文件拒绝 | 直接断言草稿数组归零 |
  | `AttachmentMergeCopyOwnershipTest`（1） | 会话副本与草稿**不同实例**；擦除草稿后会话字节完好 | 无 `copyOf` 时 `===` 断言必红 |
  | `AttachmentSameNameEditSaveTest`（既有 1） / `AttachmentDataOwnershipTest`（既有 4） | 回归不受影响 | — |

- **行数分档**：`EntryEditViewModel` 位于 400~500 档并已压线（500）；本次以「压缩一条既有注释 + 新增两行」

## 4. 限制与后续边界

- 草稿数组的**会话副本**在保存路径交出后由仓库负责清零（既有契约）；本批未新增仓库侧清零断言。
- 未做设备侧附件导入 / 保存 / 锁定重开实跑（宿主用例以引用观察数组内容）；该路径属既有 AVD 冒烟范畴。
- `wipeDrafts()` 在锁定时会移除未提交的草稿附件（与口令等明文同等处置），属安全取向的有意取舍；
  重开编辑页后不恢复草稿。
