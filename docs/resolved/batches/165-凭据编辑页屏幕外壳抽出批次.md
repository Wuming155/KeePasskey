## 2. 状态所有权刻意留在母文件

`showIconPicker` / `showDiscardDialog` **没有**跟着下沉。原实现里「选中图标 → 同时关对话框」是
**一个动作的两半**；若把关闭动作也交给子组件自持，就会出现「关对话框」有两处真相的漂移面。
故子组件只收窄回调，复合动作留在 `EntryEditContent` 的 lambda 里（逐字保持原顺序）：

```kotlin
onSelectIcon = { onIconChange(it); showIconPicker = false },
onSelectCustomIcon = { onSelectCustomIcon(it); showIconPicker = false },
```

丢弃弹窗的三条出口（放弃 / 继续编辑 / 点遮罩）也全部落到母文件传入的两个 lambda，
`onDismissRequest` 与「继续编辑」同义（原实现即如此），不引入新语义。
