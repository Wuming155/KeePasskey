## 3. 过程留痕（真实发生）

1. **删 import 的自动化把运算符导入删掉了**：脚本按「符号名是否还在正文出现」判失效，
   而 `androidx.compose.runtime.getValue` / `setValue` 是 `by remember` 委托的**隐式运算符导入**，
   正文里根本不出现这两个名字 ⇒ 被误删，编译期报
   `Property delegate must have a 'getValue(...)' method`。**处置**：手工恢复两条 import 后编译通过（未入库）。
   教训：**Kotlin 的运算符 / 委托类 import 不能用名字检索判失效**，此类清理须以编译器为准。
2. 一次临时文件写到 bash 与 python 不同的 `/tmp` 视图（Windows 下两者不同根），导致中间产物读不到；
   改为直接从 `git show HEAD:<path>` 重取原文再抽取，避免依赖跨工具的临时目录。
