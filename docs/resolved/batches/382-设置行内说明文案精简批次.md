## 1. 整改

**整改总口径**（三参考项目调研的公约数，例证原文均由调研子代理照录并附路径）：

- 开关行内 `_sub` 只留一句「是什么/做什么」，删「关闭后…」后果链与冗余括号；
- KeePassDX：同位开关（Credential provider service）连 summary 都不写（`preferences_form_filling.xml:25-28`）；解释抽成独立 info 行跳帮助（`NestedAppSettingsFragment.kt:162-165`）；长警示只在切换那一刻弹窗交付（`NestedAppSettingsFragment.kt:178-199`）；
- keepass2android：安全开关「No DAL verification」的解释也止步一句 "Disables check if domain and app package match"（`strings.xml:320`）；全仓最长设置 summary 约 250 字符也只到 "Only disable this option if you understand the risk."（`strings.xml:352`）；
- Monica（同为 Compose + M3）：主开关说明一句 "Turn Monica autofill on or off at app level."（`strings.xml:4048`）；页面级背景上移页顶信息卡，不塞开关行。

### 1.2 过程缺陷（如实）

- **首版英文 `autofill_skip_dal_sub` 用了未转义撇号**（"calling app's"），`mergeDebugResources` fail-closed 编译失败（"Invalid unicode escape sequence"）；改为 "the site-published ownership statement of the calling app" 后通过。全量首轮失败于资源编译期（58s），未污染测试结果。
- 仓库既有串对撇号用 `\'` 转义（如 `unlock_msg_weak_kdf`），本批改用无撇号表述，两法均合法。
