## 1. 整改内容

### A 组：同屏重复渲染（4 处登记 + 1 处整改中发现）

1. **A1 · TOTP 设置页查找顺序双述**：`totp_presets_desc`（中英）删去与页底 `totp_info_desc`
   逐义重复的「配置的字段名会优先用于查找；未命中时回退…」句——顶部卡片只保留「插件差异 +
   预设用途」，查找顺序 / 参数缺省 / 引擎兼容统一页底信息卡单点承载。
2. **A2 · 动态取色与调色盘互斥三述**：`theme_dynamic_sub`（中英）删「；开启期间下方主题调色盘
   暂不生效」从句。**`ISSUE-P3-263` AC⑤ 不降级**：置灰原因说明仍由调色盘侧
   `theme_palette_dynamic_notice` + 「改用主题调色盘」一步切回按钮承载
   （`ThemePaletteMutualExclusionWiringTest` 4 处断言原样全绿）；
   `theme_palette_pick_desc` 保留——它描述**点选动作后果**（互斥切换），与状态性 notice 职责不同。
3. **A3 · 系统填充下拉两行同文**：`AutofillPickerActivity.deliver` 改为标题/副行分工——
   `menuTitle` = 用户名 → 条目标题（`getKdbxEntry` 单条读取，`runCatching` 对锁定竞态降级空）
   → `autofill_picker_title` 三级回退；`menuSubtitle` 仅在用户名非空时显示条目标题，否则空串
   （`autofill_dataset_item` 的 `tv_subtitle` 为 `wrap_content`，空串即零高度行）。
   **同根因第 5 处**（登记后整改中发现）：`AutofillConfirmActivity.deliver` 在用户名为空时
   `menuTitle`/`menuSubtitle` 双双等于 `credentialTitle`，同批同法修复（副行条件化为空）。
4. **A4 · Argon2 对话框当前值双显**：`dbset_argon2_memory_label` / `dbset_argon2_parallelism_label`
   去掉内嵌数值（中英）；芯片行改为 `(预设档位 + 当前值).distinct()` 并集——当前值**恰显示一次**
   且总在选中 chip 上。不能只删标签数值：库参数可来自外部工具（`argon2MemoryMb` 取自
   `kdf.memoryInBytes`，未必落在 16/32/64/128/256 预设档位），无并集兜底会直接丢信息。
