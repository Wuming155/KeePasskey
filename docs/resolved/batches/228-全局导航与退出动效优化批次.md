# §228 全局导航与退出动效优化批次

> 对应条目：`ISSUE-P3-222`（结案）  
> 闭环日期：2026-09-20  
> 涉及模块：`app`

---

## 1. 背景与原貌（原样收录自 ISSUE-P3-222）

- **核实时间点**：2026-09-20 经 `KeePasskeyApp.kt:352-353` 与 `AndroidManifest.xml` 源码核实
- **核实方式**：
  - `app/src/main/java/com/keepasskey/app/ui/KeePasskeyApp.kt:352-353` 经源码核实：`NavHost` 仅声明 `enterTransition = { fadeIn() }` 与 `exitTransition = { fadeOut() }`，完全缺失 `popEnterTransition` 与 `popExitTransition`，导致任何页面退出与返回均为生硬淡出或突兀切回，无层级纵深感；
  - `app/src/main/AndroidManifest.xml` 经源码核实：未声明 `android:enableOnBackInvokedCallback="true"`，系统级 Back-to-home 桌面缩放预测性动画与跨 Activity 平滑退出未显式开启；
  - 顶层 Tab（VaultList、Authenticator、Generator）与二级下钻页面未做层级动效分流。

---

## 2. 整改方案与架构落地

遵循 Google 开发者知识库（Jetpack Compose / Navigation Compose 2.8+ / Material 3 Motion System / Predictive Back）官方规范：

1. **系统级预测性返回（Back-to-Home 与多 Activity 退出）**：
   - 在 `app/src/main/AndroidManifest.xml` 的 `<application>` 节点加入 `android:enableOnBackInvokedCallback="true"`，系统级 Back-to-home 桌面缩放与窗口缩进手势动效全局开启。
2. **Material 3 共享轴（Shared Axis X）下钻转场与手势预测联动**：
   - 新增 `app/src/main/java/com/keepasskey/app/ui/navigation/AppNavigationMotion.kt`：
     - `ENTER_DURATION_MS = 300` / `EXIT_DURATION_MS = 250` / `FastOutSlowInEasing`；
     - `defaultEnterTransition`：新页从右滑入（`slideIntoContainer(Towards.Start)`）+ 淡入；
     - `defaultExitTransition`：旧页向左视差微移（`slideOutOfContainer(Towards.Start, -width / 4)`）+ 淡出；
     - `defaultPopEnterTransition`：上一级页面从左侧视差恢复（`slideIntoContainer(Towards.End, -width / 4)`）+ 淡入；
     - `defaultPopExitTransition`：当前页向右滑出（`slideOutOfContainer(Towards.End)`）+ 缩放淡出（`scaleOut(targetScale = 0.9f)`），手势边缘滑动实时跟随手指 Progress 驱动。
3. **顶层同级 Tab 贯穿淡入淡出（Fade Through）**：
   - 在 `KeePasskeyNavGraph.kt` 中为 `Unlock`、`VaultList`、`Authenticator`、`Generator` 明确声明 `topLevelEnterTransition` 与 `topLevelExitTransition`，杜绝底部 Tab 切换时发生空间层级混乱的横向位移；同时 `VaultList`、`Authenticator`、`Generator` 的 `popEnterTransition` 继承 `defaultPopEnterTransition`，下钻详情返回时完美衔接。
4. **守卫用例锁定**：
   - 新增 `AppNavigationMotionTest`（4 例）锁定动效规范常量、清单声明、`KeePasskeyApp` 全局接线与 `KeePasskeyNavGraph` 顶层 Tab 接线不变式。
